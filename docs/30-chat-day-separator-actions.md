## 二、实现

### 2.1 跨天分隔（`ChatScreen.kt`）

- `ChatRow` 新增 `Day(label)`；
- `buildRows` 在拼行时比较 `dayKey(createdAt)`（年 + 一年中的第几天），变化就插一条 `Day`；
  连续 assistant 分组跨天也会断开（组内发现换天先收口当前组）；
- `dayLabel`：今天 / 昨天 / `M 月 d 日` / 跨年带年份；
- `rowKey` 用 `d:<label>`，LazyColumn 的 key 稳定；搜索行号映射对 `Day` 是 no-op。

### 2.2 消息长按菜单

- `ChatScreen` 顶层状态 `actionTarget: ChatMessage?`；用户气泡长按设置它 → `MessageActionDialog`
  （AlertDialog：复制 / 引用 / 重发 / 取消，带一行说明文案）；
- 「引用」= `quotePrefix(text) + 原输入`，然后 `focusInputTick += 1` 让 `LaunchedEffect`
  重新请求输入框焦点并弹键盘（输入框加了 `focusRequester`）；
- 「重发」只对**用户消息**出现，且 `streaming` / 只读会话时禁用（`canResend`）；
- 「引用」在只读会话里不出现（`canQuote`）。

### 2.3 为什么助手正文不给菜单

实测（第一版）长按助手正文会**同时**弹我们的菜单和系统的「复制/全选」工具条，
两层浮层叠在一起很难看。助手正文外面本来就有 `SelectionContainer`（`MarkdownText`），
系统选择对「选一段代码/一句话」更实用，所以：

- 助手正文：保留系统选择，移除我们自己的长按 handler；
- 用户气泡（普通 `Text`，没有选择容器）：长按走我们的菜单。

要引用助手的话，目前得先用系统选择复制——**引用任意消息**留到下个里程碑（需要消息级"..."按钮）。

## 四、没做 / 已知限制

1. **引用只是文本前缀**，不是结构化 quote：消息里不会记录「引用了哪条」，渲染也就是普通 markdown 引用块。
2. **重发** = 追加一条新的同文用户消息；没有「删除原消息/截断后续」的编辑重发。
3. 助手消息的「重新生成」没做（需要删除后续事件或分叉会话，属于会话层能力）。
4. 导出会话（Markdown）没做。
5. 多天**边界**只在代码层保证：旧版导入会话多为单日短会话，没抓到一张「同屏两个日期分隔」的截图；
   「今天」「8 月 24 日」「8 月 27 日」三种标签形态都已真机出现。
