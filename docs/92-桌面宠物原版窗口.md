## 一、本批做了什么

用户对悬浮窗插件的红线是「**完完全全把那个悬浮窗移过来，不是自己再画一遍**」（M64 原话）。
本批搬的是第二个插件：`dsh-client-ui-pet` —— DSH Web GUI 的页面内序列帧桌宠。

- **窗口里跑的是插件自己的 `lib/client.js`**（59.5KB / 1216 行，vendored 到 `web/ui-pet/src/upstream-client.js`，
  一字未改）；动作表、优先级/打断规则、坐姿映射、拖拽甩出、双击轮换、长按害羞、右键菜单、
  动作点播滑动选择器、设置面板、粒子特效、台词池全部是上游代码。
- **素材就是插件 `assets/pet/` 的原图**：23 组动作 / 1006 张 220×220 透明 PNG，
  构建时转 WebP q90（alpha 逐像素不变），57.0MB → 11.2MB，随 APK 分发。
- 宿主只替换三件事：素材地址（没有 proxy-bridge）、帧扩展名、token 汇报（没有 tokenUsage 投影），
  见 `web/ui-pet/build.mjs`（每处替换都有断言）。
- 新增 `fish/PetWebService.kt`：`TYPE_APPLICATION_OVERLAY` 透明硬件 WebView（280×360dp）；
  位置 `uipet_x/uipet_y`；单指事件全部给页面；双指拖窗口、松手吸附四角；双指轻点打开原版菜单；
  「隐藏桌宠」→ 收起；前后台优先级：3D 鲸鱼娘 > 桌面宠物 > 大肥鱼 > 悬浮球。
- 会话联动：`BigFish` 快照（running / pending / nodes）经 `__petSession(json)` 喂给上游
  `hookSession`，任务开始→surprise→think、审批→wait、出错→cry、完成→happy/dance 都是上游逻辑。
- 插件映射：`NativePetAdapters` 新增 `PETWEB`（只认 `dsh-client-ui-pet`），导入自动开；
  插件详情标题「原版窗口已接入：dsh-client-ui-pet（23 组序列帧桌宠）」。
- 设置 → 显示与行为 新增「桌面宠物（23 组序列帧）」：开关 + 重置窗口位置 + 说明。

## 三、实现要点

### 3.1 页面（`web/ui-pet/`）

- `src/upstream-client.js`：上游 `lib/client.js` 原样（仅去 CRLF）；
- `src/page.js`：宿主适配层 ——
  - 定义 `__ModuleLoader__` 收集 entry，按 `entry.factory()` → `apply(ctx)` 执行（和 DSH 一样）；
  - `ctx.get('sessions')` 用 `DSHNative.state()` 的 BigFish 快照伪装成 sessions 面，
    native 状态变化时 `__petSession(json)` 触发上游 `hookSession`；
  - 单指 `touchstart/move/end` → 合成 `mousedown/mousemove/mouseup/dblclick`（上游只认鼠标），
    拖动时同步 `DSHNative.moveWindowBy` 移窗口，上游 drag/fling/snap 状态机照常跑；
  - 双指轻点（native 识别）→ `__petOpenMenu()` 派发 `contextmenu`；
  - 上游「隐藏桌宠」挂出 chip → `DSHNative.collapse()` 收起整个悬浮窗；
  - 首帧 load 后重摆一次启动气泡（上游挂载时 pet 高度为 0）。
- `src/index.html`：透明页面；`!important` 把角色钉在窗口右下角（`left/top` 交给 native）。
- 产物 `app/src/main/assets/pet/{index.html,pet-client.js,page.js,whale-pet.png,pet/…}`。

### 3.2 宿主（`fish/PetWebService.kt`）

- 窗口 280×360dp：上游动作选择器 240×300、设置面板 230（含 padding ≈254）都放得下；
- 默认右下角，`uipet_x/uipet_y` 持久化；拖动后按窗口中心吸附最近屏幕角（180ms 动画）；
- 双指：拖动移窗口；轻点（<350ms 且位移 <8dp）打开原版菜单；
- 单指：全部交给 WebView（页面翻译成鼠标事件）；
- 会话：`BigFish.state` collect → `running = THINKING/WORKING/WAITING`、`pending`、本 turn 的
  `tool-result` / `turn-error` 节点，`__petSession` 推给页面；
- 前台收起/退后台出现，与 3D 鲸鱼娘/大肥鱼同一套 `DshApplication` 优先级。

## 四、没做 / 限制（诚实标注）

- **动作点播的「滑动选择」在触摸上只能点选**：上游那块是 `mousedown`+`mousemove` 拖动与
  `wheel`，Android WebView 没有滚轮、`<div>` 拖动也没有原生语义；列表项点击播放没问题。
- **token 统计/每日预算没有接**：鲸歌内核还没有 `tokenUsage` 投影，为避免显示假数字，
  上游的 token 汇报时机改成一次 happy 动作（`build.mjs` 第 5 处替换），设置面板的预算输入
  仍可改但不影响显示。
- **右键菜单改为双指轻点**；「重置位置」菜单项只改页面内坐标（视觉被钉住），窗口位置请用
  双指拖或设置页的「重置到右下角」。
- **双指手势 adb 无法注入**：菜单/拖动路径是用 CDP 调 `__petOpenMenu()` / `DSHNative.moveWindowBy`
  验证的；单指拖动是 `adb shell input swipe` 真触摸验证的。
- **主题**：透明 WebView 没有 DSH 主题变量注入，上游菜单/面板用 CSS 浅色兜底（#fff/#1c2333），
  与鲸歌深色主题不一致；这是上游 CSS 的默认值，没有改。
- **窗口是 280×360dp 的透明区域**，空白处仍会被 WebView 吃掉触摸（与 M64 的 3D 鲸鱼娘同一个
  取舍）；窗口本身可以双指拖到任意角落。
- 没有搬上游的「坐姿吸附输入框上方」：Android 没有 DOM composer，`findComposerRect()` 找不到
  输入框，所以只有站姿 idle 基线（6 组坐姿动作仍可在动作点播里点播）。
- 1006 张帧随 APK 分发（+9.5MB，APK 122.6MB）；上游 `files` 不含 assets，安装包本身拿不到帧。
