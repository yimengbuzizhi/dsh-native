> 日期 2026-11-06｜目的：证明这台机器能编出「Kotlin + Compose」的可装机 APK。

## 二、网络探测（旧项目里 `github.com` 不通，所以必须单独验）

| 目标 | 结果 |
|---|---|
| `dl.google.com/dl/android/maven2/...` | **200 OK** |
| `repo.maven.apache.org/...` | **200 OK** |
| `services.gradle.org/distributions/` | **200 OK** |
| `api.github.com` | **200 OK** |

结论：Gradle + Google Maven + Maven Central 全通，**不需要本地镜像**，构建链路可走标准 AGP 路线。

## 三、选型

| 项 | 选择 | 理由 |
|---|---|---|
| 构建 | Gradle 8.9 + AGP 8.6.1 | 与 JDK 21、SDK 34 兼容；AGP 8.6 稳定 |
| 语言 | Kotlin 2.0.21 | 与 Compose 编译器插件同版本 |
| UI | Compose（BOM 2024.09.03）+ Material3 | 原生控件、无 XML 布局 |
| compileSdk / targetSdk | 34 | 本机已装；35 可后续 `sdkmanager` 补 |
| minSdk | 24 | 与旧版覆盖面对齐（旧版 minSdk 24） |
| applicationId | `xin.dshaa.nativeapp` | 自有域名空间，**不与旧版 `com.deepseek.harness` 冲突**，可共存装机 |

- [ ] 装到真机并打开探针页

## 五、失败预案

| 失败点 | 预案 |
|---|---|
| AGP 与 JDK 21 不兼容 | 降 AGP 到 8.5.x / 8.4.x，或用 JDK 17（本机另装） |
| Compose 依赖拉不下来 | 用 `--offline` 前先跑一次在线；仍失败则改用 Views + 手写 UI（工期 ×1.3） |
| AAPT2 在本机执行失败 | 换 build-tools 35.0.0 / 关闭并行 |
