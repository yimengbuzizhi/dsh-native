# 120 · 远程 DSH：给 AI 的部署契约（M83 阶段 4）

> 给「用户电脑上的 AI」看的：照这份契约做，就能让手机上的鲸歌通过**独立小助手**连上这台电脑的 DSH。
> 不改 DSH 本身：不装插件、不改代码、不改配置。
> 手机侧：设置 → 远程 DSH → 填「地址 + 令牌」→ 测试连接。

## 一、组成部分

```
手机（鲸歌） ──HTTP+Bearer token──> 小助手（独立进程，本机/Tailscale） ──带签名 cookie 的 HTTP──> 本机 DSH
```

- **小助手**：`tools/dsh-remote/helper.mjs`（仓库里，Node ≥ 18，无依赖）。
- **secret**：只在小助手进程的内存里用。不写盘、不打印、不传给手机、不进仓库。
- **令牌**：手机和助手之间用的短码，默认随机 8 位并保存到 `~/.dsh-remote/token`。

## 二、部署步骤（AI 执行）

1. 确认 DSH 在跑：`curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:63167/`（不是 000 就算在）。
2. 确认凭据文件存在：`~/.dsh/.credentials.yaml` 里有 `client-connection/browser-session.secret`
   （**不要打印这个值**）。
3. cookie 名**不用再手动找**：小助手按 DSH 0.2.2-rc.1 的算法自己算——
   `dsh-auth-` + `base64url(sha256(<host:port>))`（HTTPS 用 origin），
   并用 `~/.dsh/.credentials.yaml` 里 `client-connection/browser-session.payload.secret`（32 字节 base64url）
   现签 cookie 值 `v1.<payload>.<hmac>`，每个请求重签、1 小时有效。
   如果健康检查返回 `dsh: "http 401"`，通常是 DSH 地址（端口）和 cookie 的 authority 对不上，
   或 `.credentials.yaml` 里的 secret 刚被替换；先确认 DSH 地址，再重启小助手。
   特殊部署可用 `--cookie-name <名字>` 覆盖。
4. 启动：
   ```
   node tools/dsh-remote/helper.mjs --port 8137 --dsh http://127.0.0.1:63167
   ```
   记下它打印的「令牌（短码）」和某个 `100.x`/`192.168.x` 地址。
5. 防火墙/网络：
   - 局域网：放行 8137；
   - 外网/异地：用 **Tailscale**（手机装 Tailscale 登录同一账号），用 100.x 地址；
   - **不要把 8137 直接映射到公网**。
6. 验收：电脑上 `curl http://127.0.0.1:8137/api/health` 返回
   `{"ok":true,"dsh":"reachable","api":"ok",...}`（`api:"ok"` 表示 `/api/session/list` 也通）；
   手机填同一地址 + 短码，点「测试连接」应显示已连接并列出会话。

## 三、接口（手机端只依赖这三个）

| 方法 | 路径 | 认证 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/health` | 不需要 | `{ok:true, dsh:"reachable"|"http 401"|"unreachable: …", api:"ok"|"error: …", dshUrl}` |
| ANY | `/api/dsh/*` | `Authorization: Bearer <短码>` | 原样转发到 DSH 本地端口（助手注入 cookie，去掉手机令牌/Origin/Host） |
| WS | `/api/dsh/*` | 同上 | WebSocket 升级同样透传（手机用 `/api/dsh/api/remote.mux` 收会话流） |

手机端讲的是 DSH Web 客户端自己的协议（一元 `POST /api/<endpoint>`、会话流 `/api/remote.mux`），
助手只做认证 + 转发，不写业务逻辑。具体帧格式与用到的 endpoint 见 `docs/121`。

## 四、安全底线

- secret 不进手机、不进仓库、不进日志；助手只打印令牌和地址。
- 助手默认只监听 `0.0.0.0`，**必须**配 token；没有 token 的请求一律 401。
- 建议助手只在需要时启动（和手机「按需连接」一致）；任务结束就关。
- 手机侧连接也按需：跑任务时才起前台服务 + 常驻通知（复用 `TurnKeepAliveService`），断开即退出。
