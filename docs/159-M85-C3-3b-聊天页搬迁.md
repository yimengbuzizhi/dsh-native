## 1. 依赖处理（搬之前先切断 5 条反向依赖）

| UI 原来直接用的 | 处理 |
|---|---|
| `chat.ChatMirror.attachText` | `NativeShellHost` 新增 `attachTextFile(name,text): Boolean`（109→110 成员，`AppViewModel` 加 override）；ChatScreen/ChatComposer 新增 `onAttachText` 回调 |
| `data.BuiltinPageIds` | 纯 id 词表，搬进 `ui:shell-api` 根包 `xin.dshaa.ui.shellapi.BuiltinPageIds`，全仓 FQN/import 更新 |
| `data.McpConfigStore` / `data.McpServer` | 搬进 `ui:shell-api.data`（Android+Compose+JSON，与 `SettingsStore` 同类） |
| `device.attach.AttachmentCapture` | ChatComposer 改收 `notificationsEnabled` / `onOpenNotificationAccess` / `onAttachNotifications` 三个回调；结果类型 `NotifyAttachResult` 放 shell-api.chat，宿主 adapter 把 `AttachOutcome` 映射过去 |
| `device.attach.LocationCapture` | ChatComposer 改收 `onAttachLocation(context): Boolean` |
| `memory.MemoryPickerDialog` / `buildMemoryReference` | ChatComposer 改收 `memoryPicker` **Composable 槽**（`onDismiss` + `onPick(name,text)`）；宿主选择器负责生成引用正文，UI 只把它变成待发附件 |
| `chat.READ_ONLY_IMPORT`/`READ_ONLY_SUBAGENT` | 常量搬进 `shellapi.chat`（AppViewModel/ChatScreen import 更新） |
