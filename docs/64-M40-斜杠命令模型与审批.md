## 一、一句话结果

- `/` 菜单现在三条宿主命令：`/plan`、`/model [名字]`、`/permission [auto|ask]`；
- `/model` 不带参数 → 打开输入条那个**模型面板**（与点模型 pill 同一个 `ModalBottomSheet`，
  最近模型、识图开关、联网搜索、打开模型配置都在里面）；带参数 → 直接切 `settings.model`，
  顶栏/输入条立刻变，notice 写「模型已切换为 X」；
- `/permission` 不带参数 → 新的**工具审批面板**（每次询问 / 自动允许，选中态打勾）；
  带参数 → 直接改 `settings.approvalMode`（与设置 → 行为同一个值），notice 写结果；
- 参数非法（`/permission deny`）→ 拒绝 + 用法提示，**不改任何设置**；
- 两条命令**都不建会话文件、不产生模型消息**（用户只是想换模型，不该多出一条空会话）；
- 命令表从 UI 挪到 `:core:input`（`CommandCatalog.kt`），`/` 菜单、派发、以后的 `/help` 共用一份；
- 单测：`:core:input` 15 → **18 条**；全量 15 模块 **398 条 0 失败**；
- 顺手核对：**branch / 重新生成早已实现**（docs/06 的「未做」是陈旧记录，已在本轮改正）。

## 二、规则

| 输入 | 结果 |
|---|---|
| `/model` | 打开模型面板；不建会话、不写日志事件 |
| `/model deepseek-reasoner` | `settings.model` 切换，notice「模型已切换为 …」 |
| `/model 名字 里 有 空格` | 拒绝：「模型名不能带空格：/model <名字>」 |
| `/model "带引号的名字"` | 去引号后按不带空格处理（`unquoteArg`） |
| `/permission` | 打开审批面板（当前档位打勾） |
| `/permission auto` / `always` / `allow` | 改为自动允许 |
| `/permission ask` / `every` / `confirm` | 改为每次询问 |
| `/permission deny` / 其他 | 拒绝 + 用法（当前档位），设置不变 |
| 只读会话 / 旧版导入副本 | `submit()` 之前就拦掉，命令不执行 |
| 技能与宿主命令同名 | 宿主命令优先（与上游一致）；目前没有叫 `model`/`permission` 的技能 |

为什么 `/model`、`/permission` 不落 `command/run`：它们只改客户端设置，不碰会话，
上游也只有真正作用于 agent 的命令才写 command 事件。`/plan` 仍照旧写（它落 `plan/mode`）。

## 三、实现

| 层 | 文件 | 改动 |
|---|---|---|
| `:core:input` | `CommandCatalog.kt`（新） | `CommandChoice(name, description, usage)` + `display()`；`DSH_COMMANDS`（plan/model/permission）；`findCommand()`；`parseApprovalArg()` 别名归一化 |
| `:core:input` | `CommandCatalogTest.kt`（新） | 名字唯一且能被 `parseCommandLine` 解析、三条命令都在、用法文案、审批参数别名 |
| App | `InputTriggerPanel.kt` | 删掉本地 `CommandChoice`/`DSH_COMMANDS`，改 import core；行标题用 `display()`（显示 `[名字]` 用法） |
| App | `ChatSessionState.kt` | `pendingCommandSheet: CommandSheet?`（`MODEL` / `PERMISSION`）+ `enum CommandSheet` |
| App | `AppViewModel.kt` | `submit()` 派发 `model`/`permission`；`executeModelCommand` / `executePermissionCommand` / `approvalLabel` / `unquoteArg`；`Log.i("DshCmd", …)` |
| App | `ChatComposer.kt` | `approvalMode` / `onSetApprovalMode` 参数；`LaunchedEffect(state.pendingCommandSheet)` 消费信号（并打 `sheet: … consumed` 日志）；新的审批面板 `PermissionChoiceRow` |
| App | `ChatScreen.kt` / `App.kt` | 透传 `settings.approvalMode` 与 `setApprovalMode` |

面板是 Compose 局部状态（`modelSheet` / `permissionSheet`），命令在 ViewModel 里解析，
所以用 `pendingCommandSheet` 这个一次性信号交接；Compose 侧消费后立刻置空。
