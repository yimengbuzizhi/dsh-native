# 09 · Operit UI 拆解与三方案取舍

> 2026-11-06｜用户：「Operit UI 也好看，看看他的」。
> 对象：[AAswordman/Operit](https://github.com/AAswordman/Operit)（Kotlin + Compose，**LGPL-3.0**）。
> 对比：[RikkaHub](https://github.com/rikkahub/rikkahub)（**AGPL-3.0**，只能学设计不能抄代码）。

---

## 一、Operit 的 UI 长什么样

从它仓库的官方截图看（`docs/assets/readme/*.png`）：

| 页面 | 特征 |
|---|---|
| 聊天 | 全宽渐变头图（蓝），白色大标题 + 等宽小字；消息用**浅蓝卡片**，卡里嵌白色工具行 |
| 任务执行 | 顶部步骤胶囊 `01 需求 → 02 工具 → 03 预览 → 04 交付`；工具执行逐行列出（read_file / edit_file + 增删行数 + 状态点）；diff 整行绿/红 |
| 文件变更 | 文件头 + `+12 −8`，等宽字体，行内高亮 |
| 记忆 / 角色 | 白色表单面板 + 蓝色滑杆；角色列表带头像和选中勾 |
| 底部输入 | 模型 chip + 一排图标 + 蓝色圆形发送 |

### 它的 8 个手法

1. **全宽头图**：渐变/图片 + 白色标题，第一眼就有"产品感"
2. **卡中卡**：外层浅蓝卡（`#F4F8FF` + `#DCE6F6` 描边，圆角 16），里层白色小卡装工具行
3. **工具行**：图标 + 等宽工具名 + 文件名 + `+12 −8` + 状态点，一行一个动作
4. **思考过程可折叠**：chevron + 灰字 + 步数
5. **diff 整行底色**：绿 `#E6F4EA` / 红 `#FCE8E6`，等宽字体，文件头带统计
6. **步骤胶囊**：当前步骤实心蓝，其余浅底
7. **蓝色高饱和**：`#2F6FE0` 做主色，浅蓝做面，白做底
8. **信息密度高**：适合"工作台"，不适合"闲聊"

## 二、和 RikkaHub 的差别（一句话）

| | RikkaHub | Operit |
|---|---|---|
| 底色 | 暖白 `#F7F5F0` | 纯白 + 浅蓝面 |
| 结构 | 无卡片，靠留白 | 卡中卡，靠描边 |
| 色彩 | 几乎无颜色 | 蓝面 + 蓝强调 |
| 性格 | 安静、像阅读器 | 专业、像工作台 |
| 适合 | 聊天页 | 任务/工具/diff/控制台 |
| 许可 | AGPL（不能抄代码） | **LGPL（可以抄）** |

## 三、我的建议：不是二选一，是按页面分工

```
聊天页           →  Rikka 的轻（暖白、无卡、大字、单一强调色）
工具/任务/diff   →  Operit 的重（浅蓝卡、卡中卡、步骤条、整行 diff）
控制台/插件页    →  Operit 的卡片语言（信息密度高，需要结构）
设置页           →  Rikka 的彩色圆片 + 白卡（已经做过一版）
深色模式         →  两者都适用，按 Operit 的深蓝面 + Rikka 的排版
```

理由：

- 聊天是"读"，要安静；工具执行是"审"，要结构。**同一套皮肤硬套两种场景，必有一边难受**。
- 旧版最大的教训就是两套视觉打架（网页 + 手绘 View）；这次不是"统一成一种"，而是"同一套 token，两种密度"。
- 许可上，Operit 是 LGPL，真要抄它的 diff/步骤条组件，法务成本最低。

## 五、其他页面（不只是聊天）

从它官方截图里能看到的其他页面，以及我们怎么对应：

| Operit 页面 | 我们的页面 | 借什么 |
|---|---|---|
| **包管理**：插件 / 包管理 / 技能 / MCP 四个标签；搜索框；每行"图标 + 名称 + 描述 + 子包数 + 开关"；右下悬浮按钮 | 插件页 / 工具页 | 四标签 + 行式开关 + 失败态红卡 + 悬浮按钮 |
| **工作区设置**：浅蓝大卡 + "创建默认 / 选择现有"两张白选项卡 | 工作区页 | 设置卡 + 二选一选项卡 |
| **终端**：黑色底 + 标签栏（可关闭）+ 等宽配色 + 底部快捷按键条（Ctrl+C/Esc/Tab/↑/↓）+ 环境配置 | 终端页 | 标签栏 + 配色 + 按键条 + 深色独立 surface |
| **工作流画布**：白底 + 彩色节点卡 + 连线（实线/虚线表示成功/失败） | 工作流页 | 节点卡 + 连线语义（后置） |
| **记忆图谱**：节点 + 关联线 + 悬浮操作按钮 | 记忆 / 知识库 | 图谱可视化（后置） |
| **角色列表**：头像 + 名称 + 描述 + 选中勾 | 助手 / 预设页 | 列表 + 勾选 |

三种页面类型，三种密度：

```
管理类（插件/工具/技能/MCP）  → 列表 + 开关 + FAB     （Operit）
环境类（工作区/终端/设备）    → 浅蓝设置卡 + 白选项卡  （Operit）
内容类（聊天/会话/设置）      → 留白 + 大字 + 少颜色   （Rikka）
```

`19-terminal.svg`（终端），总览 `design/03-pages.png`。

## 六、需要你拍板

1. **二选一，还是按页面分工的混合？**（我推荐混合：聊天 Rikka、任务 Operit、设置 Rikka、控制台 Operit）
2. 主色定 `#2F6FE0`（Operit 蓝，更亮）还是 `#2563EB`（之前的）？
3. 顶部要不要 **Operit 式渐变头图**？（有"产品感"，但每页都头图会腻，建议只在聊天页/首页用）
