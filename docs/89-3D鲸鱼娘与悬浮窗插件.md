## 一、上游调研（读过的源码/清单）

用户点名要「3D 鲸鱼娘悬浮窗插件」。社区里同类桌宠/悬浮窗插件很多，本批读了这些包的清单与结构：

| 包 | 形态 | 依赖 | 鲸歌映射 |
| --- | --- | --- | --- |
| `dsh-ventus-whale`（meto-ventus） | 浏览器 three.js WebGL 透明浮窗，3D 虎鲸：拖拽旋转 / 360° 转圈 / 爱心 / 悬停工具栏 / 大小/灵敏度/文字设置 | `dsh.client`（web）+ peer React/three + `cordis.patch.yml` | **3D 鲸鱼娘**（本批新增 `WhalePetService`） |
| `dsh-dafeiyu`（QCYTSN） | Electron 插件 + Qt/PySide/Swift 原生 Helper 窗口 | Node 子进程 + stdio 协议 | 大肥鱼（M59 `BigFishService`） |
| `dsh-plugin-whale`（Makesupper） | 3D DeepSeek 鲸鱼伴侣 + 语音合成 / 木鱼 | three.js / WebAudio | 3D 鲸鱼娘（只搬状态与 3D 形象，语音/木鱼没做） |
| `dsh-whale-girl-pet`（GHSYES） | Windows 像素鲸鱼娘桌宠：状态 / 戳 / 拖 / 缩放 | Electron 原生窗 | 3D 鲸鱼娘（形象不同，状态与手势同构） |
| `dsh-client-ui-pet`（xituisuany-max） | Web GUI 鲸鱼娘桌宠：23 组序列帧、吸附点、token 汇报 | React + 帧素材 | 3D 鲸鱼娘（帧素材未随包分发） |
| `dsh-fatfish-pet-xun209`（Xun209） | 大肥鱼桌宠（本机修正透明窗） | Electron 原生窗 | 大肥鱼 |

上游事实（`dsh-ventus-whale` 的 `package.json`）：`type=module`、`main=lib/index.js`、
`./client → lib/client.js`（477 KB）、`dsh.client.inject` 三个 client runtime、`dsh.bundle.patch`；
peer 依赖 `three@0.147` + React 18，窗口在浏览器里画。**Android 没有 WebGL 透明窗、也没有 React/DSH client runtime**，
所以按「原生替身」处理：Host 侧状态照收，窗口用原生 Canvas 3D 复刻。

## 二、鲸歌实现

### 2.1 `fish/WhalePetService.kt`

- `TYPE_APPLICATION_OVERLAY` 前台服务，`WhaleView` 纯 Canvas 画 3D 低多边形虎鲸：
  - 身体：13 圈 × 14 段的椭圆截面网格（头钝尾细），尾鳍（x-z 水平两瓣）、背鳍、左右胸鳍；
  - 透视投影（相机距离 4.2）+ 面法线明暗 + 画家算法（按重心 z 从远到近）；
  - 虎鲸配色（深背 / 白肚 / 眼上白斑）+ 眼睛高光 + 腮红 + 粉色蝴蝶结（「鲸鱼娘」）；
- 交互（照 ventus）：单指拖拽旋转（灵敏度可调）、点按 360° 转圈 + 冒 5 颗爱心、
  双指拖动窗口、长按收起；
- 状态文案：复用 M59 的 `BigFish` 状态机（思考中 / 忙起来了 / 需要你点一下 / 这轮做完了 / 出错了），
  设置里可关；
- 生命周期与其它悬浮窗一致：应用退后台出现、回前台收起；优先级 **3D 鲸鱼娘 > 大肥鱼 > 悬浮球**
  （`DshApplication` 里三选一，避免互相遮挡）。

### 2.2 设置（设置 → 显示与行为 → 3D 鲸鱼娘悬浮窗）

`whale3d_enabled / whale3d_scale(0.6–1.6) / whale3d_sensitivity(0.4–2.5) / whale3d_caption`，
对应 ventus 的 size / sensitivity / 显示文字。

### 2.3 插件包映射（`fish/NativePetAdapters.kt`）

- `dafeiyu` / `fatfish` → 大肥鱼；
- `ventus` / `whale` / `dsh-pet` / `client-ui-pet` → 3D 鲸鱼娘；
- 导入命中时：自动打开对应悬浮窗开关，notice 追加「已启用原生 …悬浮窗」，插件详情显示「已原生适配」卡片
  （标题与说明按类型区分）。
- 验收夹具：`D:\dsh\ventus-fixture`（1 KB，真实 three.js 包不上手机），logcat：
  `DshPet: native adapter enabled kind=whale3d for dsh-ventus-whale`，
  `shared_prefs: whale3d_enabled=true`。

## 四、本批没做的（诚实标注）

- 原版 three.js 模型/材质/悬停工具栏/语音合成/木鱼：没有搬，Android 用低多边形网格近似；
- 真正「3D 二次元鲸鱼娘」形象（人物模型）：没有素材，当前是虎鲸 + 蝴蝶结 + 腮红的拟人化画法；
- 吸附点、token 汇报、页面内轻量角色、余额：未做；
- 语音/音效只有 M59 的提示音开关，没有 TTS。
