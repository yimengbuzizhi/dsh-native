# 07 · 界面设计方向（原生 = 要好看）

> **v0.2 变更（2026-11-06）**：看过 RikkaHub 后调整方向 —— 默认 **暖白浅色**、少颜色、大字排版、
> 圆角卡片、品牌蓝只做强调；本文 §三 的「深海」保留为**深色模式**。拆解与采用见 `08-RikkaHub-UI拆解.md`，
> 概念图见 `design/01-overview-v2.png`。

> 2026-11-06｜用户要求：**页面既然做成原生，就要做得好看。**
> 本文定三件事：视觉方向、设计系统、逐页设计要点。**默认好看，仍然可定制**（旧版 4 层主题能力不丢）。

---

## 一、旧版为什么"不好看"（先认清问题）

| 问题 | 原因 |
|---|---|
| 两套视觉 | 聊天页是 DSH 网页（React），控制台是手绘 View（9,955 行），字体/圆角/间距都不一致 |
| 控件是"拼"的 | 手写 `cButton()`、卡片背景色、1px 描边，没有状态层（pressed/focused/disabled） |
| 动效缺失 | 页面切换无过渡，列表无渐入，弹窗硬切 |
| 排版粗糙 | 中文行高、字重、数字对齐都没调 |
| 主题是"覆盖" | 4 层主题能改颜色，但改不了"质感"——因为底层控件本身没有质感 |

原生版从第一天就用一套设计系统，这些问题自然消失。

## 二、三个方向（选一个）

### 方向 A：Material 3 Expressive（活力、Android 正统）

- **气质**：明快、圆润、有弹性；大标题、大色块、spring 动效
- **优点**：最"原生 Android"，和系统动画/返回手势天然一致；动态取色（Material You）开箱即用
- **缺点**：像 Google 系 App，辨识度低；Expressive 组件在 Compose 里还偏新，稳定性要挑版本
- **适合**：想要"一看就是正规安卓 App"

### 方向 B：深海（品牌向、克制高级）★ 推荐

- **气质**：深海蓝底 + 鲸鱼品牌 + 克制留白 + 细腻层次；暗色是主角，亮色同等打磨
- **优点**：有辨识度（一眼认出是 DSH）；和现有品牌色 `#4D6BFE`、小鲸鱼、深空青主题一脉相承；暗色 OLED 省电
- **缺点**：需要自己调一套 token 和组件皮肤，工作量比 A 多约 2 周
- **适合**：想要"产品感"，不只是"能用的工具"

### 方向 C：iOS 风（克制、留白、毛玻璃）

- **气质**：大标题、分组列表、细分割线、半透明材质
- **优点**：干净、熟悉，中文排版容易做舒服
- **缺点**：在 Android 上是"拟 iOS"，返回手势/系统控件会打架；用户会觉得"这不是安卓"
- **适合**：受众以 iPhone 转过来为主（不是我们的情况）

**推荐 B**：底子用 Material 3（组件、无障碍、动效规范都现成），皮肤做成"深海"，
这样既有平台正确性，又有品牌辨识度。

## 三、设计系统（方向 B）

### 3.1 颜色

| Token | 暗色 | 亮色 | 用途 |
|---|---|---|---|
| `brand` | `#4D6BFE` | `#4D6BFE` | 主按钮、选中态、链接 |
| `brandBright` | `#6E86FF` | — | 暗色下的高亮（避免纯蓝发闷） |
| `bg` | `#080B12` | `#F6F7FB` | 页面底 |
| `surface` | `#111725` | `#FFFFFF` | 卡片 |
| `surfaceHigh` | `#1A2233` | `#FFFFFF` | 悬浮/弹层 |
| `stroke` | `#232C3E` | `#E6E9F0` | 分割线、描边 |
| `text` | `#E9EEFB` | `#161B26` | 主文字 |
| `textSub` | `#8E99AD` | `#6B7280` | 次要文字 |
| `success` | `#31C48D` | `#1F9D6B` | 运行中、成功 |
| `warn` | `#F5A524` | `#B26B00` | 注意 |
| `danger` | `#F05252` | `#D9503F` | 危险、删除 |
| `accentGlow` | `#4D6BFE22` | `#4D6BFE14` | 选中背景、聚焦环 |

规则：
- 暗色不用纯黑（`#000`），用 `#080B12` 避免 OLED 拖影和对比过硬
- 蓝不铺大面积（超过 20% 屏幕会廉价），只做强调
- 状态色只用于"状态"，不用于装饰
- 支持**动态取色**（Android 12+）：默认关，设置里可开（Material You 用户会喜欢）

### 3.2 字体与排版

- 字体：系统默认（中文思源黑/苹方回退），数字用等宽变体（`FontFeatureSettings "tnum"`）
- 字阶（sp）：`34 / 28 / 22 / 17 / 15 / 13 / 11`
- 行高：正文 1.55，标题 1.25，代码 1.45
- 字重：Regular 400 / Medium 500 / SemiBold 600（不用 Bold 700，中文会糊）
- 中文标点：全角优先；数字与英文两侧留 0.25 个字间距

### 3.3 间距 / 圆角 / 层次

- 间距基数 4：`4 / 8 / 12 / 16 / 20 / 24 / 32`
- 页面左右边距 20；卡片内边距 16
- 圆角：卡片 16、按钮 12、输入框 14、弹层 24、消息气泡 18
- 层次用「明度差 + 1px 描边」表达，少用阴影（暗色下阴影几乎看不见）
- 唯一允许的阴影：弹层与吸底输入栏（`0 8dp 24dp rgba(0,0,0,.35)`）

### 3.4 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 页面切换 | 280ms | FastOutSlowIn |
| 弹层/面板 | 240ms | 弹性（低阻尼） |
| 列表渐入 | 180ms，错峰 20ms | 线性 |
| 流式文字 | 逐 token 追加，不重排 | — |
| 状态点脉冲 | 1.6s 循环 | 正弦 |

原则：**动效只解释"东西从哪来"，不做装饰**；所有动效可被系统「减少动画」关闭。

### 3.5 图标与插画

- 图标：Material Symbols Rounded（24dp），线宽 400
- 品牌图形：小鲸鱼只出现在启动页、空状态、悬浮球；不要在每页都放
- 空状态：一句人话 + 一个操作，不放插画堆

## 四、逐页设计要点

### 4.1 聊天页（核心）

```
┌───────────────────────────────┐
│ ‹ 会话标题            ⋯   ⊕   │  顶栏 56dp，标题可点开切换
├───────────────────────────────┤
│                               │
│  你                           │  用户消息：右对齐，brandGlow 底，圆角 18
│  ┌──────────────────────┐     │
│  │ 帮我把这个函数改成异步 │     │
│  └──────────────────────┘     │
│                               │
│  ● 已读取 3 个文件             │  工具调用：紧凑一行，点开展开
│  › 编辑 src/math.ts   ✓       │
│                               │
│  助手正文（全宽，不套气泡）      │  AI 消息：无气泡，行宽 ≤ 34 汉字
│  ...                          │  代码块：深色块 + 行号 + 复制
│                               │
├───────────────────────────────┤
│ ＋  输入…              ⚙  ▷  │  输入栏：模型名在 ⚙ 里，语音/附件在 ＋
└───────────────────────────────┘
```

- **AI 消息不套气泡**（套了显廉价，且长文难读）；用户消息才有气泡
- 工具调用折叠成一行：图标 + 摘要 + 状态点（运行中脉冲 / 成功勾 / 失败红）
- 流式时只追加不重排（用 KMP 渲染器 + 批量重组）
- 长按消息：复制 / 引用 / 重试 / 删除
- 审批：底部弹层（不是全屏对话框），显示**原文** + 允许一次 / 总是允许 / 拒绝

### 4.2 会话列表

- 分组：今天 / 昨天 / 更早
- 行：标题（1 行省略）+ 最后一条摘要 + 时间
- 左滑删除（进回收站）、长按多选
- 顶部搜索框常驻（会话多时是刚需）

### 4.3 控制台（原生首页）

- 顶部：状态卡（引擎/模型/网络）+ 一行关键指标
- 分组卡片：会话 / 插件 / 设备能力 / 主题 / 日志
- 每张卡：标题 + 状态点 + 一句副标题 + 箭头
- 危险操作（清空、恢复默认）永远红字、单独一块、放最下面

### 4.4 设置

- 分组列表，行高 52，左侧 24dp 图标，右侧值 + 箭头
- 搜索：设置项多，顶部加搜索
- 开关用 Material 3 Switch，行点击也能切换

### 4.5 插件页

- 卡片：图标 + 名称 + 版本 + 权限 chips（`fs` `net` `shell`）+ 开关
- 失败态：红点 + 一行错误摘要，点开看原文
- 安装：底部按钮「安装并启用」，装完立刻可开关

### 4.6 主题页

- 顶部：当前主题实时预览（一张缩略的聊天页）
- 内置预设 6 套（深海 / 深空青 / 极简白 / 纸墨 / 高对比 / 跟随系统）
- 「自定义」→ 4 层编辑器（外观/布局/文案/动作），改一项预览立刻变
- 导入导出沿用旧版 JSON 规范（契约不变）

### 4.7 终端 / 浏览器 / 虚拟屏

- 终端：等宽字体、光标块状、软键盘上方的快捷键条（Ctrl/Esc/Tab/↑↓）
- 浏览器：地址栏 + 页签横滑 + 同屏按钮
- 虚拟屏：`ShowerSurfaceView` 全屏，悬浮工具条（返回/Home/截图/关闭）

### 4.8 启动页

- 深色底 + 小鲸鱼 + 一行「正在准备…」，**不显示进度条**（原生没有长时间的初始化）
- 冷启动目标：< 800ms 到首屏

## 五、可定制性（不能丢的旧能力）

旧版主题 4 层：外观 / 布局 / 文案 / 动作。原生版映射：

| 旧层 | 原生实现 |
|---|---|
| 外观 | 设计 token 覆盖（颜色/圆角/字体/背景图/logo） |
| 布局 | 卡片顺序、显隐、`layout.pages` 声明式控件树 → Compose 渲染 |
| 文案 | 文案键覆盖（沿用旧 schema） |
| 动作 | `http` / `intent` / `prompt` / `shell`，红框 + 确认（红线不变） |

**新增**：主题可以导出成"设计 token + 组件变体"，比旧版只改颜色更彻底。

## 六、实现与验收

| 项 | 做法 |
|---|---|
| 组件库 | `:ui:design` 模块：Color/Type/Shape/Motion token + 基础组件（Card/Row/Sheet/Chip/Empty/Skeleton） |
| 预览 | 每个组件加 `@Preview`（亮/暗/大字号三态） |
| 性能 | 列表 60fps；首屏 < 800ms；流式 1000 轮不卡 |
| 无障碍 | 对比度 ≥ 4.5:1；支持字体缩放 200%；所有可点元素 ≥ 48dp |
| 验收 | 每页截图对照设计稿；暗/亮/大字号三套；真机 60fps 录屏 |

**视觉验收清单**（每页过一遍）：
1. 暗色下没有"灰得发脏"的层级
2. 亮色下没有"白得刺眼"的大面积
3. 中文行高不挤、不散
4. 主按钮只有一个视觉重心
5. 空/错/加载三态都有设计
6. 动效可关
