## 2. 浮动窗对共享模块的 import（允许）

```
app/.../device/floating/ui/fullscreen/FloatingFullscreenScreen.kt
  import xin.dshaa.ui.shellapi.chat.ATTACHMENT_REFERENCE_HINT   （壳契约常量）
  import xin.dshaa.ui.design.chat.QuotedAttachment              （共享设计组件，已下沉）
  import xin.dshaa.ui.design.chat.consumeInnerScroll
  import xin.dshaa.ui.design.chat.parseQuotedAttachment
  import xin.dshaa.ui.design.component.MarkdownText
  import xin.dshaa.ui.design.theme.DshTheme / DshTheme2

app/.../device/floating/ui/window/FloatingWindowScreen.kt
  import xin.dshaa.ui.design.chat.QuotedAttachmentChip
  import xin.dshaa.ui.design.chat.parseQuotedAttachment
```

说明：`:ui:shell-api` 是壳/宿主共享契约模块，`:ui:design` 是共享设计模块；
两者都不是「内置 UI 插件实现」，`app` 依赖它们不违反宿主骨架边界。
