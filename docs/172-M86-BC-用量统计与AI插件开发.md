## 请求用量

本片修复有源码和 fixture 证据的缺陷，不宣称已捕获用户那次下降的唯一根因。

- TokenUsage 使用可空累计快照，缺字段与真实 0 分开。Anthropic 总输入包括非缓存输入、cache-read、cache-creation；OpenAI prompt_tokens 已包含缓存子项，不重复相加。
- OpenAI 请求 include_usage，finish_reason 后继续读取 choices=[] 的尾部 usage，直到 DONE 或 EOF；JS 供应商晚到输入 usage 也传播。
- TurnEngine 对累计输出赋值合并，修复重复相加；每次 attempt 独立编号，开始、流中、成功、失败、取消均报告同一请求快照。
- App 将输入总数、缓存子项、窗口、分段估算绑定在同一请求；不再以新估算配旧真实数。缺 usage 显示未报告，真实零可见；压缩/工具修剪/图片卸载后标明等待下一请求。
- 三段比例是文本估算，以最大余数法分配实际输入，总和严格守恒。没有使用历史 max 隐藏合法下降。诊断 `dsh_context_usage` 只导出身份、数量与变化事件，不含正文或凭据。

验证：protocol/llm/engine **126 项**全部通过（15 项新用量用例）；model 新增 **4 项**守恒/零/下降测试。HTTP interceptor 使用真实 SSE reader/client，覆盖 finish→usage尾包、EOF、缺失/零、缓存与重复累计值；引擎覆盖失败/取消/重试归属。

真机同会话确定性供应商：12000→8000→0，缓存子项10000→6000→0，真实总数和面板标注正确。证据 `docs/m86b-context-check.json`、`docs/m86b-context-check.log`、`tools/m86b-context-check.py`、`docs/shots/m86b-02-context-panel.png`。

真实 OpenAI 通道请求返回 **Insufficient Balance**，输入/输出均未报告，界面正确清空旧用量。证据 `docs/m86b-context-real.json`、`docs/shots/m86b-01-real-usage.png`。**真实上游成功 usage 尚未验证，未抓到用户原故障对应响应。** 离线供应商显式标作 fixture，验证后停用并恢复跟随协议。

## AI 插件工具与技能

内置工具组 `builtin.plugin.dev` 可停用，提供：

- plugin_dev_list / test：查询和隔离 apply 试运行，沿用只读工具审批。
- plugin_dev_scaffold / install / enable / reload：生成目录/安装/启停/重载，沿用现有写工具审批策略。
- plugin_dev_call：实际调用已启用、已接入的插件工具，复用现有 schema/权限/超时。
- plugin_dev_test_shell：临时真实 QuickJS runtime 执行 apply/mount/state/action，校验 Surface 或 HTML；空会话、空服务快照，外部能力拒绝，宿主命令只记录、不切当前壳、不渲染页面。
- plugin_dev_test_capability：经现有 CapabilityHost 真正调用已授权能力。

随包中文技能 `dsh-plugin-authoring` 覆盖包格式、ctx API、各角色、生命周期、权限、示例、装测及回退。API 参考补 shell/agent/storage/prompt 登记，并纠正“无常驻运行时”旧说明。

目录和 zip 共用 PluginPackage 边界与 PluginStore；安装先暂存、真实试运行，通过后备份旧包/替换/核验 registry。失败回滚旧包；首装清理失败报告残留位置。所有 Store mutation 共享实例锁。目录打包拒绝符号链接、越界、超限；删除只处理确认过的插件子目录且不跟随链接。

同 id install 沿用重装语义：保留新 schema 兼容配置，启用插件并收回旧危险授权；reload 保留新清单仍声明的授权。不会自动授危险权限、自动选壳或执行 npm 脚本。当前事务是进程内异常恢复，未实现断电恢复日志。

配置试运行已统一 JS Config → manifest schema，裁剪旧值并合并默认值；修复 manifest-only 配置登记与实际执行不一致。Surface 模板按钮已用真实 label 属性。

验证：App **19 项**专项测试全部通过（12 包/配置/事务边界，7 离屏验证与生命周期）。真机真实 QuickJS **22/22**：工具生成/apply/安装/列表/调用/停用/重载，坏版本安装保留旧工具，Surface 与 WebView mount/state/action，能力调用/停用，未授权 shell 确实拒绝。证据 `docs/m86c-plugin-dev-selftest.json`；测试包保留在专用测试目录，创建的插件均停用，不删用户数据。

构建/单测日志 `docs/m86bc-build-test.log` 与 `docs/m86bc-build-final2.log`；首轮自测入口 BuildConfig 未限定包名编译失败已修，最终构建成功。页面回归结果见 HANDOFF 最新段。
