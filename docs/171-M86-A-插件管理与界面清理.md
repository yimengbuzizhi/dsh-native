## 已实现

- 插件页使用「导入 / 内置 / 角色」TabRow、搜索和 LazyColumn，没有状态/类型筛选 chips。
- 导入与内置列表均保留停用项；展示来源、启停状态、使用中与工具接入状态。点行可看详情，开关仍走现有后端。
- 角色页集中界面壳、回合、存储、提示词、模型和能力。壳选择可直接切换，不必先停用原生壳；不可用候选保留原因。
- `builtin.shell.whale` 随包 JS 壳归入内置页签。插件 API 静态参考移到顶栏「帮助」，与运行时能力提供方分开。
- 安全模式可打开插件管理、选择其他可用壳，也保留重新启用原生界面；恢复管理通过壳契约渲染原生插件页，不经过第三方页面覆盖。onboarding 保留原生实现。
- 修复回合选择行只传插件 id 的歧义，改为 `插件id#回合id`。
- 删除插件页底部长篇开发说明及旧“核心不可关”列表。
- 助手页删两段解释 banner：角色卡/侧栏切换的长说明、内部 prompt 段拼装说明。保留插件预设复制/卸载行为说明与所有配置字段。
- 设置入口旁移除「跟随系统 / 设备 / 远程 / 共用 / 不含密钥 / 只读」badge；备份不含密钥仍在副标题中说明，页面内部有效状态和安全提示保留。
- 空正文回合不再产生“发继续”notice，保留诊断日志及其他停止/错误提示。
