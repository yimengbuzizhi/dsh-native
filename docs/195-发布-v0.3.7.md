## 七、已知限制 / 未覆盖

- 真机只覆盖 arm64（PEMM00）；x86_64 模拟器无 `libnode.so`，Node 宿主 FAILED 是已知边界。
- `max_tokens=256000` 只实测 DeepSeek 官方端点；其它 OpenAI 兼容端点若报 `max_tokens too large`
  目前需用隐藏调试通道下调，没有自动降级。
- 安全模式不归因单个插件；恢复后仍崩会再次进入。
- 首次解压 1.2GB 期间 Node 工具不可用；低存储设备需要预留约 1.9GB。
- 公开源码树不含 Node 运行时 zip（见 §三）；公开树要跑 `NodeRuntimeInstallerEntryCountTest`
  需先补回 `runtime.zip`。
