## 当前限制总表（照实说）

1. `ui.view` 未实现——非上游 API，暂不设计鲸歌自有视图协议。
2. 客户端插件宿主只跑 Web 半侧（Node 主进程能力不可用，与 0.3.2 相同）。
3. 插件模型的工具参数一次给全（无 `input_json_delta` 逐字）；取消只退 Flow 不退 JS（最长 180s 自愈）。
4. 投影 checkpoint 只对打开过的会话存、节流 1.2s + 回合边界、`stateVersion` 不一致整条作废。
5. Node 兼容面：fs 只文本、Buffer 不接 TypedArray、`spawn` 抛错、`crypto/url/stream` 未支持。
6. 导入插件的能力取决于插件自己；本报告只对「宿主 + 内置」负责。
7. **未发布**：开发树 0.3.2 / versionCode 5，发布树仍是 v0.3.2；发布前要把内容给用户确认。
