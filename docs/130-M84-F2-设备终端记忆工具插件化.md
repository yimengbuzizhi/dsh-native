# 130 · M84-F2：设备 / 终端 / 记忆工具归入内置插件组

> 2026-11-13 20:3x。F 验收时发现空壳仍有 **26 个非内置工具**进 `tools[]`（设备桥 / 终端 / 记忆）。
> 本小批不新增插件，只把这 26 个工具归进已有内置插件组，让「23 个内置插件全关」= `tools[]` 真的为 0。
> 证据：`docs/m84f2-check.json`、`docs/f2-*.json`。本批未发版。

## 一、做了什么

`BuiltinPlugins` 的三个已有组补上工具名（组数/插件数仍 23）：

| 组 | 新增工具 | 个数 |
|---|---|---|
| `builtin.shell` | `create_terminal_session` / `execute_in_terminal_session` / `execute_hidden_terminal_command` / `input_in_terminal_session` / `close_terminal_session` / `get_terminal_session_screen` | 6 |
| `builtin.page.device` | `device_info` / `dump_ui` / `click_element` / `tap` / `long_press` / `swipe` / `press_key` / `input_text` / `launch_app` / `capture_screenshot` / `start_virtual_display` / `close_all_virtual_displays` | 12 |
| `builtin.memory` | `query_memory` / `get_memory_by_title` / `create_memory` / `update_memory` / `delete_memory` / `link_memories` / `query_memory_links` / `move_memory` | 8 |

这 26 个工具不是 `BuiltinToolCatalog` 提供的（是 app 里的 `AndroidDeviceTools` / `TerminalTools` /
`MemoryTools`），所以 `AppViewModel.syncBuiltinTools()` 增加一段：按 `BuiltinPlugins` 的工具名映射
到 app 工具实例，组开 = 注册、组关 = 从 `ToolRegistry` 注销。`BuiltinToolCatalog` 仍是 32 个工具 /
12 个组；内置插件仍是 23 个。

## 二、真机结果

### 空壳

- 23 内置全关 + 30 导入插件全停；
- `toolsAll = 0`、`toolsOffered = 0`（F 时是 26）；
- 页面仍只剩 Plugins / Settings；聊天/插件页/设置页可用；
- 冷启动 1839 / 1832 / 1853 / 1842 / 1842 ms，中位数 **1842 ms**。

### 全装配

- 内置恢复默认（22 开 + 悬浮窗示例默认关），导入插件 19/30；
- `toolsAll = 126`、`toolsOffered = 126`、catalog 32、插件工具 68、页面 22/22，与 F 一致；
- 冷启动 1852 / 1847 / 1842 / 1837 / 1873 ms，中位数 **1847 ms**。

### 三组单独关（reset 后只关一个组）

| 关掉的组 | `tools[]` | 启用页 | 说明 |
|---|---|---|---|
| `builtin.shell` | 126 → **118** | 21（Terminal 关） | 少 8 个：bash/working_directory + 6 终端工具 |
| `builtin.page.device` | 126 → **114** | 19（虚拟屏/无障碍/权限 关） | 少 12 个设备工具 |
| `builtin.memory` | 126 → **118** | 21（Memory 关） | 少 8 个记忆工具 |

三个数都与预期精确一致；测试后已 `reset` 回全开。

## 三、限制 / 未做

- 只是**工具归组**；页面内容仍是 Kotlin/Compose，未插件化。
- M84-B 142 项逐页对拍仍未重跑（F 的 22 条路由冒烟仍有效）。
- release 冷启动未测；`operit-extended-http` 15s 超时未解决。
- 设备工具归 `builtin.page.device`、记忆工具归 `builtin.memory` 之后，关「设备页面组」会连设备工具一起关，
  关「记忆库」会连记忆工具一起关——这是刻意的一致语义，不是独立开关。
- 本批未发版。

## 四、对「一切皆插件」终点的影响

- 终点条件 1「空壳能启动」更实了：关掉全部 23 个内置插件后，模型侧 `tools[]` 为 **0**。
- 仍未满足完整终点：页面实现未插件化、常驻 JS 运行时（`ui.registerView` / `sessionProjections` /
  `llm stream`）未做、供应商选择 UI 未做、0.3.2 功能只抽样对齐。
