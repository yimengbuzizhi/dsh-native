1. **空壳能启动**：`dsh_builtin_off all` 冷启 → 安全模式「界面插件已停用」+「重新启用原生界面」；

   `disabled=[]`、`unowned=[Plugins,Settings]`、工具表 **130** 项（与 M84 收口一致；
   0.3.2 对拍见 `docs/141`/`docs/142`）；M84-B **142/142**。
3. **任意一块能换**：本轮在最终 APK 上复跑三个 demo——
   - **换壳**：WebView 壳 `m85f.webview-shell`（第三方 HTML 界面，`shell/v1` webview 后端）；
   - **换回合**：Echo agent `m85d.echo-agent`（输入 `M85F-AGENT` → 回复 `ECHO: M85F-AGENT`）；
   - **换存储**：只读导出存储 `m85e.readonly-storage`（135 条 `[导出]` 会话，active 只读）。
   三者停用/恢复后都回内置实现，数据不丢。
4. **发版准备完成（未发布）**：`docs/143` 草案已扩成 v0.3.3 内容（M83+M84+M85 A~F），
