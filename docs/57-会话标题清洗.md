## 一、规则

`SessionTitle.from(text)`（`core/engine/SessionTitle.kt`）：

1. 取第一行非空文本；空行和以 ` ``` ` 开头的代码围栏行跳过；
2. 去掉行首 `#{1,6}`、`>`、`-/*/+`、`1.` 之类的 Markdown 符号；
3. 去掉行内反引号；
4. 连续空白（含制表符）压成一个空格；
5. 最多 **24** 个字符（UI 负责省略号）；空消息回「图片」。

不额外发 LLM 请求：本地清洗已能解决「标题里带一堆 Markdown」的问题；
「LLM 起名」等用户明确要再说（多一次请求/费用）。

## 三、边界

- 只是启发式：不会理解语义，也不会把「帮我写一个登录页」缩成「登录页」；
- 不处理 `/命令` 前缀（命令触发的会话标题还是命令原文，后续可单独处理）；
- 24 字符是硬上限，英文长单词会被截断（UI 省略号）；
- 没有改历史会话标题，只影响新会话。
