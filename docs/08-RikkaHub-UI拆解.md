# 08 · RikkaHub UI 拆解与采用

> 调研 2026-11-06｜对象：[rikkahub/rikkahub](https://github.com/rikkahub/rikkahub)（8.6k star，Kotlin + Compose，**AGPL-3.0**）
> 用户评价：**「UI 做得挺舒服的」**。本文拆它为什么舒服，以及我们怎么用。

---

## 一、先看它是什么

- 原生 Android LLM 客户端，**Material 3 Expressive**（`MaterialExpressiveTheme` + `MotionScheme.expressive()`）
- 技术栈：Compose、Navigation 3、Koin、Room、DataStore、Coil、OkHttp、kotlinx.serialization
- 主题：seed 色 + 动态取色（可选）+ 预设主题 + 自定义主题 + AMOLED 纯黑
- 卡片用 `surfaceContainer` / `surfaceBright`，顶栏同色，**几乎没有阴影**
- 有一整套 10 级色板（red/orange/green/blue/gray × 10），用来给图标做彩色底

## 二、为什么它「舒服」——11 个手法

| # | 手法 | 具体做法 | 我们抄不抄 |
|---|---|---|---|
| 1 | **暖白底** | 背景 `#F7F5F0`，不是纯白；卡片纯白，靠明度差分层 | ✅ |
| 2 | **消息不上卡片** | 助手正文直接排在背景上，只有用户消息有个浅灰气泡 | ✅ |
| 3 | **用户气泡不用品牌色** | 浅灰 `#EAE7DF`，品牌色只留给发送按钮/链接 | ✅ |
| 4 | **助手开头报身份** | 小图标 + 模型名（MONO 小字）+ 正文，像"谁在说话" | ✅ |
| 5 | **操作行弱化** | 复制/重试/编辑用小号描边图标，灰色，不抢注意力 | ✅ |
| 6 | **元信息极小** | token 数 10sp 灰色居中 | ✅ |
| 7 | **输入框是大胶囊** | 占满宽度、28 圆角、浅底，右侧扫一扫 | ✅ |
| 8 | **只有一个彩色实心** | 发送按钮是页面上唯一的实心彩色 | ✅ |
| 9 | **设置页彩色圆片** | 每个设置项一个 34dp 圆形色底图标（蓝/紫/粉/绿/琥珀） | ✅ |
| 10 | **大字排版** | 页面标题 30–32sp 粗体，正文 16–17sp，行高 1.6 | ✅ |
| 11 | **expresssive 动效** | 转场 spring，输入框展开、按钮回弹 | ✅（Compose 自带） |

## 三、它没有、我们必须有的东西

RikkaHub 是"聊天客户端"，不是 agent，所以：

| 我们的东西 | 怎么融进这套风格 |
|---|---|
| 工具调用卡 | 不做成大卡片，做成一行浅底 chip（图标 + "已读取 3 个文件" + 箭头），点开展开详情 |
| 权限/审批 | 底部 sheet，白底圆角 28，原文 + 三个按钮 |
| 控制台 | 用同一套语言：白色圆角卡 + 彩色圆片图标 + 大数字 |
| 插件页 | 白色卡 + 权限 chip（浅灰小胶囊）+ 开关 |
| 主题页 | 预览卡 + 预设色块 + 分组列表 |
| 深色模式 | 同等打磨：`#121311` 底、`#1C1D1A` 卡片、文字 `#F2F0EA` |

## 五、许可证（重要）

RikkaHub 是 **AGPL-3.0**，比 Operit 的 LGPL 更严格：

| 做法 | 结论 |
|---|---|
| 学设计、自己写 Compose | ✅ 没问题（风格/布局不受版权保护） |
| **复制它的 `.kt` 源码** | ⚠️ 会让整个 App 变成 AGPL，且网络服务条款也生效 |
| 用它的某一屏截图当参考 | ✅ 可以，但不要直接贴进产品 |

**结论**：只学设计，不复制代码。我们的代码仍是 LGPL-3.0（与 Operit 一致）。
如果未来想直接搬它的组件，需要把整个 App 改成 AGPL——这是一个产品级决定，不是技术决定。

## 七、和第一版（深海）的关系

第一版（v0.1）是深色科技风，第二版（v0.2）是 Rikka 的暖白舒适风。
**建议以 v0.2 为主**：默认浅色（暖白），深色同等打磨；品牌蓝保留但只做强调。

这也解决了一个隐患：旧版控制台是"深色卡片堆"，和聊天页两套观感；v0.2 用一套语言覆盖两者。
