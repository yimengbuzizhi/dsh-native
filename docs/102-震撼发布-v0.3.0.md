## 三、Release 说明要点（用户视角，不写内部代号）

1. **多助手配置**：多份角色卡（名字/头像/简介/人设/开场白/系统提示词），侧边栏一键切换，
   人设与系统提示词按 DSH 语义注入。
2. **客户端插件宿主**：插件自己的界面跑在鲸歌里（桌宠、鲸鱼娘挂件 3D 舞台 + 木鱼功德 + 设置面板）；
   插件本体不随 APK 分发。
3. **插件适配**：提示词变量 `{{...}}` 替换、社区人设/预设插件（`cordis.patch.yml`）可用；
   插件权限/配置/重载。
4. **隐私与数据清理**：占用统计 + 网页缓存/Cookie、临时文件、头像缓存清理（二次确认）。
5. **模型浮层**：精修；模型列表多选，只切换已启用的模型。
6. **引用附件/包**：发送后只显示可折叠 chip（模型仍拿全文）。
7. **体验修复 7 条**：功能页返回设置、无障碍顶栏、设置滚动保持、计划模式可撤销、
   宽屏常驻侧边栏、切模型保留浮层、模型多选。
8. 另外还有：记忆库、Operit 包管理（31 个内置包）、终端/读屏、备份恢复等 M55–M74 的累积能力。

## 四、诚实限制（会写进 Release 说明）

- 仍是**预发布**、debug 签名；功能/数据格式可能变。
- 客户端插件宿主只跑插件 Web 半侧：Node 主进程能力（`ctx.provide`/`node:path`/`webServer`）不可用，
  `dsh-plugin-whale` 的 3 个工具未注册；pet 窗口在 Android 12+ 仍是 0.8 透明度（无适配层时的系统限制）。
- 插件提示词变量是 **apply 时快照**，要刷新需「重载插件」。
- `cordis.patch.yml` 只解析「助手预设」；不自动安装子插件、不执行其它 config。
- 引用 chip 只识别发送时的两种附件形状（历史消息同样按渲染规则识别）。
- 宽屏常驻侧边栏断点 600dp；折叠屏半折/平板横屏吃这一条。
- 终端首次在新设备展开 61MB rootfs 可能超过上游 30s 上限。
