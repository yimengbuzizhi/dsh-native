## 二、这个版本用户能看到什么

1. **插件能换掉/加上任何一块**：工具、页面（含替换内置页）、提示词段、模型供应商、插件自己的模型回合、
   回合钩子、会话存储、会话投影、事件订阅、清理器、通知、设备/终端/记忆、悬浮窗四分口、客户端插件 UI。
2. **界面壳也由插件决定（M85-C/E/F）**：默认仍是原来的原生界面（内置 `builtin.shell.native`，体验不变），
   但可以切到 Surface 壳或**整屏 WebView 壳**（同一套 `shell.mount/state/action/event` +
   `surface.command` 桥）；停用/崩溃自动回原生；同 id 第三方壳可接管。
3. **回合/存储/提示词/模型都是插件角色（M85-D/E）**：默认 `builtin.agent.dsh` / `builtin.storage.jsonl` /
   `builtin.prompt.dsh` / `builtin.model.*` 就是现有 native 实现；可停用（安全提示，不丢数据）、
   可同 id 覆盖、覆盖后回退原实现。第三方 storage v1 是只读导出器（能浏览、不能写）。
4. **能力契约 `capability/v1`（M85-F）**：root / NFC / Shizuku / ADB shell 等特权能力**不写死在宿主**，
   由插件 `ctx.capability.register` 提供；宿主只做登记 + `capability` 权限门 + 超时；
   没有提供方时如实显示「不可用」。内置只有 notify/clipboard/share 这类骨架平台原语。
5. **插件自己产出模型**：`ctx.llm.register({stream})`——插件在常驻 JS 运行时里拿到完整请求体，
   逐 token 回传、可发起工具调用（真机：插件模型调 `m84m_ping` 出工具卡再回最终答复）。
6. **会话投影 + checkpoint**：插件收到每条会话事件折叠状态；App 重启只重投新事件（真机 `lastSeq=25`、0 条重放）。
7. **Node 兼容面**：Buffer / EventEmitter / timers / path / fs(+promises) / os / child_process / http，
   真机真实插件 22/22 通过（含 base64/hex、UTF-8 中文、`fetch example.com` 200）。
8. **空壳能启动**：内置插件全关 + 导入插件全停时仍然进聊天/设置/插件页；`tools[]=0`；安全模式可一键恢复。
9. **全装配不少于 0.3.2**：22/22 页、catalog 32、插件工具与 M84 收口时持平或更多；
   M84-B 页面回归 **142/142**；冷启动 < 2s 量级（M84 记录 1.89s）。
10. **界面**：远程 DSH 页（M83）、插件整页进抽屉、「关于」整页、插件详情里的 stream/投影/checkpoint 信息、
    插件页的存储/提示词/模型/能力分组（M85）。

## 四、已知限制（会写进 Release 说明）

1. `ui.view` 未实现——真实 DSH 包里也没有这个 API（非上游预留），不假装支持。
2. 客户端插件宿主只跑 Web 半侧（与 0.3.2 相同）。
3. 插件模型的工具参数一次给全（无 `input_json_delta` 逐字）；取消只退 Flow，JS 侧最长 180s 自愈。
4. 投影 checkpoint 只对打开过的会话存、节流 1.2s + 回合边界；`stateVersion` 不一致整条作废。
5. Node：fs 只文本、Buffer 不接 TypedArray、`child_process.spawn` / `crypto` / `url` / `stream` 未支持。
6. 工具参数说明仍是中文（0.3.2 已知限制延续）。
7. **M85 新增限制**：
   - 第三方 storage v1 只读（不能新建/写入/回收站/分支）；投影 checkpoint 仍是宿主缓存；
   - WebView 壳没有 Surface 的 `bind`，流式每 ~500ms 整段重绘；只允许内联 HTML/CSS/JS
     （`blockNetworkLoads`，不能绕过 net 权限）；Surface 原语的 `webview.url` 仍不开放；
   - capability/v1 的调用入口是插件页/调试通道，插件之间互调能力尚未开放；
   - 浮动窗 Surface 插口只支持静态树（没有 chat 绑定），JS `ctx.floating.*` 仍未开放；
   - native 默认实现不做 DEX 动态加载（第三方 native 壳不会进 APK）。
