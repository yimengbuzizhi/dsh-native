# 115 · 「一切皆插件」的终点与剩余工作（M83 之后接着干）

> 背景：docs/114 是 M83 本批（UI 修复 + 底盘骨架 + 样板 + 开桥 + 远程）的验收清单。
> **那只是地基，不等于「一切皆插件」完成。** 本文定义终点和剩余清单，做完 114 后按本文继续，不要停。

## 一、终点（三条，全部满足才算完）

1. **空壳能启动**：把所有插件关掉，App 还能打开到「插件管理」，不崩、不白屏。
2. **全部装配**：把内置插件全打开，功能不少于今天的 0.3.2（32 个工具、20 个页面、聊天、包管理、技能、MCP、悬浮窗、定时、子代理……）。
3. **任意一块能被换/加**：任选一个功能，装一个插件就能替换它或给它加东西（工具、页面、提示词、模型、回合流程、悬浮窗、存储，逐项验证）。

> **2026-11-13 22:4x 用户加码（把第 3 条推到最彻底）**：「宿主只留骨架，工具/页面/提示词/模型/回合/存储/UI
> 全部由插件提供或替换」。即：**④ UI 壳由插件决定**、**⑤ 回合循环由插件决定**、**⑥ 存储由插件决定**；
> 宿主只保留原语 + 总线 + 安全/生命周期 + 平台能力（详见 `docs/144`）。M84 已完成的只是「功能插件化」，
> 主壳/回合/存储仍是宿主的，M85 负责把它们也交出去。

## 二、已经有的地基（不用重做）

- 插件装/卸/启停/权限/配置/试运行（`core/plugins`）
- 模型侧贡献：tools / promptSections / contexts / variables / commands
- Web UI 插件宿主（`dsh.client`，桌宠/鲸鱼娘那套）
- 内置 Operit 包 31 个 + 技能 + MCP 的开关（M81）

### G. 骨架化（M85，2026-11-13 用户定调）
- 用户原话：「宿主只留骨架，工具/页面/提示词/模型/回合/存储/UI 全部由插件提供或替换」。
  设计基线见 `docs/144-M85-宿主骨架与一切皆插件-设计.md`（骨架定义、契约、服务总线、Shell/Agent/Storage v1、

- **终点④**：**UI 壳由插件决定，但默认 UI 不是重画的**——宿主只有壳宿主/页面注册/Surface+WebView
  原语；默认鲸歌 UI = `builtin.shell.native`（**现有 Compose UI 原样插件化，界面与体验不变**）；
  `builtin.shell.whale`（Surface）与第三方 WebView 壳只是可选替换，不是默认、不替代原生。
- **终点⑤**：**回合循环由插件决定**——`agent/v1`；默认 `builtin.agent.dsh` 以 native 实现注册成插件，
  可停用/被同 id 覆盖，JS agent 可替换。
- **终点⑥**：**存储由插件决定**——`storage/v1`；默认 `builtin.storage.jsonl` 沿用现有会话格式，
  第三方可换（SQLite/远程/加密），宿主只给 raw file/KV 原语。
- 判定标准：宿主里出现「聊天/工具/页面/提示词/回合/会话」的产品语义 = 还没骨架化完。
- 迁移策略：**原生 UI 原样插件化，不删 UI**——把现有 Compose 页面搬进内置 UI 插件
  `builtin.shell.native`，宿主只删「私有 import/路由/页面清单」；Surface 壳只是可选第二套。
  每一步真机可回退；发布仍未获用户确认。
