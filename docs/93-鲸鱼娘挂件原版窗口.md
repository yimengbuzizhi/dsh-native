## 一、本批做了什么

用户对悬浮窗插件的红线从 M64 起就是「**完完全全把那个悬浮窗移过来，不是自己再画一遍**」。
本批搬第三个插件：`dsh-plugin-whale` —— DSH Web GUI 里的「深度求索鲸鱼娘」3D 挂件
（3D 舞台 + LLM 气泡 + 木鱼功德 + 设置面板）。调研结论（M65 交接时写的）已兑现：
素材可分离，`lib/client.js` 无外部 import，走 `web/ui-pet` 验证过的
「`__ModuleLoader__` 收 entry → `factory()` → `apply(ctx)` + `DSHNative` 桥」路线。

- **窗口里跑的是插件自己的 `lib/client.js`**（139.8KB / 3202 行，vendored 到
  `web/whale-widget/src/upstream-client.js`，**逐字节拷贝**）。3D 舞台是上游
  `whale-stage-3d.ts` 的 Canvas 2D 自绘（不是 three.js、也不是鲸歌重画）：身体/头发/尾巴/
  鳍/裙摆/表情/口型/指针视角、idle 呼吸与敲击波纹都是上游代码；
- **气泡、拖动/收起/静音 pill、功德徽章、工具栏、7 种音色、五页设置面板**也全是上游代码；
- 上游的 `/dsh-whale/*` 是 Node 侧（`whale-service.ts` / `merit-storage.ts` /
  `llm-speech-service.ts`）实现的，Android 没有 Node 宿主：页面里补了一个**同语义**的本地
  服务端（`src/page.js` 拦截 `window.fetch`），字段、108 次/批上限、±1~±1000 万 token 阈值、
  30 分钟常驻伴奏上限、句子清洗/切分/「只播最后一段」规则都照上游；
- **功德账本落 native prefs**（`WhaleMerit`，`whale_widget_ledger`，结构同上游
  `merit_history.json` 的 `days/pendingTokens`），杀进程/重装不丢；
- **会话联动**：`BigFish` 快照里新增「本轮最终回复正文 + 序号」（`AppViewModel` 在
  turn end 取最后一条 assistant 的 TEXT 块），native 经 `__whaleSession(json)` 推给页面；
  页面按上游规则取最后一段、切句入队 → 气泡逐句显示 + 每句敲一下木鱼（功德 +1）；
  THINKING / WAITING / ERROR / SUCCESS 也各推一句状态台词；
- **窗口**：`WhaleWidgetService`（`TYPE_APPLICATION_OVERLAY` + 透明硬件 WebView）
  284×300dp，位置 `whalewidget_x/y`；拖动 pill 单指拖（`DSHNative.moveWindowBy`）、
  双指拖窗口（native 兜底）；设置面板打开 → 临时加高到 470dp；上游「收起」→ 缩到 150dp
  （都保持底边，收起后不再留一整块透明窗口挡触摸）；
- **映射**：`NativePetAdapters` 新增 `WHALEWIDGET`（只认 `dsh-plugin-whale`），导入自动开；
  插件详情「原版窗口已接入：dsh-plugin-whale（3D 鲸鱼娘挂件 + 木鱼功德）」；
  设置 → 显示与行为新增「鲸鱼娘挂件（木鱼功德）」：开关 / 重置窗口位置 / 说明；
- 验收夹具 `D:\dsh\whale-fixture`（1KB 清单）+ `D:\dsh\dsh-plugin-whale-fixture.zip`。

## 三、实现要点

### 3.1 页面（`web/whale-widget/`）

- `src/upstream-client.js`：上游 `lib/client.js` 逐字节（SHA256 一致）；
- `src/page.js`：宿主适配层 ——
  - 定义 `__ModuleLoader__` 收 entry，`entry.factory()` → `apply(ctx)`；
  - `window.fetch` 拦截 `/dsh-whale/*`，在页面里实现上游 Node 侧的服务端语义：
    - `/state`：`todayMerit/totalMerit/todayTokens/totalTokens/pendingTokens/tokensPerMerit/
      accompanimentIntervalMs/modelUrl/todayKey/currentSpeech/speechSeq/ackedSpeechSeq/
      speechQueue/knockSeq/auto{…}/records`；
    - `/knock`：写 native 账本（1~108/批），返回 `{state}`；
    - `/speech-ack`：ack 句子 / 入队试听文本 / 保存节拍与模型 URL；
    - `/auto`：常驻伴奏（interval 取 `accompanimentIntervalMs`，30 分钟上限，target=0）；
    - `/tokens-per-merit`：±1~±1000 万阈值（照上游校验）；
  - 语音函数是**照搬**上游 `llm-speech-service.ts` 的三个纯函数：
    `sanitizeLlmTextForSpeech`（去 think/代码块/Markdown/URL，中英加空格）、
    `extractFinalConclusionText`（只留最后一段）、`splitTextIntoSpeechSentences`
    （句号/感叹号/分号切句，140 字上限，长句按逗号再切）；
  - Web Speech 不可用 → 首次启动把上游客户端 prefs 的 `voiceEnabled` 预置成 `false`，
    让 `bundle.ts` 走它自带的「静音也要显示 + 敲一下」降级路径（每句 900ms、有说话动作），
    而不是 `speakSentence()` 立刻 onEnd；
  - 拖动 pill：`touchstart/move/end` 用 `screenX/screenY` 调 `DSHNative.moveWindowBy`；
  - 面板/收起：`MutationObserver` 观察 backdrop 的 `display` 与 container 的 `is-collapsed`，
    调 `DSHNative.setPanelOpen / setCollapsed`；
- `src/index.html`：透明页面；`!important` 把挂件钉在窗口右下角；设置卡按窗口宽收窄、
  五个 tab 换行、面板背后不压暗（上游是全页蒙层，悬浮窗里会变成一个暗方块）；
- `build.mjs`：6 处宿主替换（token 文案 ×4、Web Speech 说明 ×2），每处断言命中 1 次，
  并校验产物仍有 `__ModuleLoader__.load` / `id: 'dsh-plugin-whale'` / `apply(ctx)`。

### 3.2 宿主（`fish/WhaleWidgetService.kt` + `fish/WhaleMerit.kt`）

- `TYPE_APPLICATION_OVERLAY` + 透明硬件 WebView，284×300dp（挂件 236px 宽 + 气泡/徽章/
  工具栏约 250dp 高）；位置 `whalewidget_x/y`，默认贴右下角；
- 单指全部给 WebView（点按敲木鱼、工具栏、面板、拖动 pill）；双指由 native 拖窗口；
- `setPanelOpen` / `setCollapsed`：改高度时保持底边（`p.y += oldH - newH`），并 clamp 在屏幕内；
- 会话：`BigFish.state` collect → `__whaleSession(json)`（`state/message/detail/project/reply/
  replySeq/updatedAt`），同一快照不重复推；
- JS 桥 `DSHNative`：`state / whaleState / whaleKnock / log / ready / moveWindowBy / endDrag /
  setPanelOpen / setCollapsed`；
- 前台收起 / 退后台出现，与桌宠/3D 鲸鱼娘同一套 `DshApplication` 优先级
  （3D 鲸鱼娘 > 桌面宠物 > 鲸鱼娘挂件 > 大肥鱼 > 悬浮球）；
- `WhaleMerit`：`shared_prefs/dsh.xml` 的 `whale_widget_ledger`
  = `{"days":{"2026-11-10":{"merit":16,"tokens":0}},"pendingTokens":0}`，
  保留 3650 天，`displayDate` 用 `M月d日 EEEE`（中文星期）。

### 3.3 `BigFish` 的扩展（M66）

- `FishSnapshot` 新增 `reply`（本轮最终回复正文，≤4000 字）与 `replySeq`（只增不减；
  `onTurnStart`/`onIdle` 重建快照时也带着它，挂件不会把旧回复再播一遍）；
- `onTurnEnd(error, reply)`：成功时把正文写进快照；`AppViewModel.startTurn` 的 finally 里取
  「最后一条 assistant 且 error 为空」的 TEXT 块拼起来传进去；
- 大肥鱼悬浮窗不读这两个字段，行为不变。

## 四、没做 / 限制（诚实标注）

- **Web Speech 朗读不可用**：Android WebView（Chrome 103）没有语音包，
  `'speechSynthesis' in window === false`。句子只显示在气泡里 + 敲木鱼，不朗读；
  发音人页是上游空状态（文案改成真话），「🔇 朗读」按钮仍可切但不会出声。
- **token 统计未接**：鲸歌内核没把每轮 token 落到消息上（`Usage` 只在压缩摘要里构造），
  四处 token 文案改成「未上报」，不显示假数字；功德只来自敲木鱼 / 回复句子节拍 / 常驻伴奏。
- **输入框不可聚焦**：悬浮窗 `FLAG_NOT_FOCUSABLE`（不抢 App 焦点），设置页的模型 URL /
  Token 输入框弹不出键盘；Token 预设按钮 + 保存可用，模型 URL 只能显示当前值。
- **窗口空白处吃触摸**：284×300dp 里挂件约 236×250，四周空白仍被 WebView 吃掉
  （与 M64/M65 同一取舍）；收起后窗口缩到 150dp 缓解。
- **双指手势 adb 无法注入**：双指拖窗口的代码与桌宠同一套（真机手测过桌宠），本批未单独截图。
- **上游 `assets/sounds/*.wav` 没有随包分发**：客户端不用它们（WebAudio 实时合成 7 种音色），
  只有 Host 侧/桌面耳返会读；不占 1.5MB。
- **木鱼音效没有做录音回环验证**：WebAudio 在真机是 `running`（CDP 新建 AudioContext 验证），
  上游 `sound-player.ts` 原样执行；是否出声受系统媒体音量影响。
- **没有搬上游的 Host 侧**：`tools/index.ts` 的木鱼/token 工具、`llm-speech-service` 的
  `session/event` 钩子（鲸歌用 BigFish 快照代替）、`cordis.patch.yml` 的默认配置。
