## 二、踩到的坑（重要）

1. **ChatScreen 子树不随状态刷新**：状态在涨（日志 messages=6）但界面停在第一条。
   试过：去掉 AnimatedContent、改 StateFlow、LazyColumn→Column，都无效。
   最终用 `key(messages.size, streaming, pendingApproval?.id)` 强制重建 ChatScreen 子树才恢复。
   怀疑是 Compose 对含大量不稳定数据（List<ChatMessage> + 自定义 data class）的子树做了错误的跳过，
   根因未坐实。**流式 token 期间可能仍不是逐字刷新**，下一步要查。
2. **`--es` 不能传布尔**：自动审批必须用 `--ez dsh_auto_approve true`。
3. **`adb shell` 里带空格的 `--es dsh_send`**：整条 am 命令要包一层引号；或先用 UI 输入。
4. **`git add -A` 会把 `.thirdparty-src/Operit` 当 embedded repo**：已加 gitignore 并 `git rm --cached`。
