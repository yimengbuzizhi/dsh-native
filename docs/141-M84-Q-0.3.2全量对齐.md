## 四、结论与已知差异

终点②「全装配功能不少于 0.3.2」：**成立**，证据是上面三张表 + 142 项页面回归。

与 0.3.2 的有意差异（都不是功能减少）：

1. 页面/工具/提示词段由**内置插件**提供（M84-A/B），关掉插件 = 页面/工具消失；全装配时与 0.3.2 一致。
2. 页面的 `Screen/SubScreen` 枚举 → `BuiltinPageIds` 字符串 id（id 不变），这样插件能注册/替换页面。
3. 新增能力：`RemoteDsh` 页（M83）、`About` 整页、插件投影/事件/清理器、插件模型（含工具回合 + 逐 token）、
   投影 checkpoint、Node 内置模块（Buffer/EventEmitter 等）。
4. 0.3.2 已知限制里仍保留的：结果气泡纯文本、上下文面板字符估算、客户端插件只跑 Web 半侧、
   工具参数说明仍是中文 —— 与 0.3.2 相同（**没有比它差**）。

  替代证据是「源码清单 + 页面/工具 dump + M84-B 逐页回归」。

  页面级回归（22 页）是 M84-B 本轮重跑的。
- 导入插件的能力取决于插件本身；本表只对「宿主 + 内置」负责。
