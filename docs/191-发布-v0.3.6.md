## 七、已知限制 / 未覆盖

沿用发布说明 §七 的 10 条，关键几条：

1. floating 容器没有可见关闭入口（双指轻点可关，用户模拟里易踩坑）。
2. 审批链可能一次请求连出多张卡；「拒绝/停止本轮」分支未在真机点。
3. 液态玻璃前台静置 CPU 明显高于原生（188 约 3.5×）；后台 88% 单核来自悬浮球常驻动画（球关 0.4%）。
4. `nodehost_control` 限流只在 JVM 测；`nodehost_autofix` 未在真机跑完整阶梯。
5. 内置提示词「关闭态」与 D 的 marker 串段只有模拟器证据；A 的六条导航真机未复验、F 真机未复验。
6. x86_64 模拟器包无 `libnode.so`/QuickJS/bash（ABI 事实）。
7. 真机观察到一次「快速操作 Node 开关时 3 个宿主进程」，未复现，下一轮专测。
