## 一、路径缩写

`shortWorkspacePath()` 其实早就在 `WorkspacePicker.kt` 里（新建工作区时用过），但设置→工作区
管理页还在显示完整路径（`/storage/emulated/0/...`），长路径把一行撑爆。这一轮把它接到管理页：

- 工作区行：`/storage/emulated/0/a/b` → `手机存储/a/b`；App 私有目录 → `应用目录/…`；
- 页脚「数据目录」同样用缩写。

## 二、打开目录

工作区行的「⋯」菜单新增「打开目录」：

- 目录存在时才出现（`exists=false` 的历史位置没有这一项）；
- 对 `/storage/emulated/0` 下的目录 → 用 `DocumentsContract` 拼
  `content://com.android.externalstorage.documents/document/primary%3A<相对路径>`，
  以 `ACTION_VIEW` + `vnd.android.document/directory` 交给系统文件管理器（DocumentsUI）；
- App 私有目录（`/data/user/0/.../files/...`）系统文件管理器打不开 → Toast「系统文件管理器打不开应用私有目录」；
- 没有能处理的应用 → Toast「没有文件管理器能打开这个目录」。

为什么用 DocumentsUI 而不是 FileProvider：FileProvider 的 `file_paths.xml` 只暴露了
`files/` 和 `cache/`，要打开 `/sdcard` 就得把整个外部存储暴露给别的 App，安全上不划算。
