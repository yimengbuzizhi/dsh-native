1. **设备只有一台**（`192.0.2.10:35789`）。任何 agent 要 `adb install` / `force-stop` / 大改设备状态前，

   `ui/shell-api/.../NativeShellHost.kt`。写之前先在 task 的 write scope 里登记。
3. **每个 task 必须有证据文件**（`docs/188-evidence/**`）与「真机跑过/没跑过」的明确标注；
   **没真机验证不许写「真机通过」**。
4. **禁 sleep 轮询**：等状态用 `logcat -d` 快照、`am start -W`、文件出现、进程退出事件。
   **不要用 `adb logcat -s TAG:I` 流式等待**——本会话里它挂死过 4 次（改为 `logcat -d` + 事件驱动）。
5. 合并方（lead）负责：跑全量测试、看 final diff、写提交。子代理**不要 commit/push**。

### 真机操作
```powershell
$adb='C:\Android\platform-tools\adb.exe'; $d='192.0.2.10:35789'
& $adb -s $d install -r --no-streaming -t app\build\outputs\apk\debug\app-debug.apk
& $adb -s $d shell am force-stop xin.dshaa.nativeapp
& $adb -s $d shell am start -W -n xin.dshaa.nativeapp/.MainActivity --es dsh_shell native

```
- **截图必须用 `cmd /c "... > file"`**：PowerShell 的 `>` 会把 PNG 写坏（本会话踩过）。
- **调试 extra 多数只在冷启动 intent 生效**（`dsh_send` / `dsh_dump_tools` / `dsh_roles_list` / `dsh_open_screen`）：
  热启动会提示 "intent has been delivered to currently running top-most instance" 且不执行，
  要 `force-stop` 再 `am start`。
- `adb shell am start ... --es dsh_send "带 空格 的中文"` 会被 `adb shell` 重新分词；
  要整条命令包一层：`& $adb -s $d shell "am start ... --es dsh_send '只回OK'"`。
- 关键 tag：`DshTurn`（`turn end after Nms`）、`DshBoot`（`firstInteractive`）、`DshPage`（`route page=…`）、
  `DshToolchain`、`DshNodeHost`、`DshCacheDebug`、`DshShell`、`DshPreset`、`DshBundled`。
- 设备 prefs 里有真实 API key：**不读、不输出、不提交**（`run-as cat shared_prefs/dsh.xml` 只许看
  `node_plugin_host_enabled` / `dsh_shell` 这类键，别整文件外传）。

### 代码坑
1. **Kotlin KDoc 里的 `/*` 会嵌套**：`/** 解 assets/toolchain/{lib/*,cacert.pem} */` 会让注释一直接到文件尾，
   报「Unclosed comment + 类没实现接口」这种完全不相关的错。写中文注释时别在 `/** */` 里出现 `/*`。
2. `ui/` 模块**不能 import `app/`** 的类（会循环依赖）——需要常量就在本模块定义一份。
3. `DshTheme2.colors` 是 `@Composable`：不能在 `drawBehind {}` / `Canvas` 里直接读，要先在外面取值。
4. 玻璃组件在原生壳下已自动退化（`liquidGlass` / `liquidEnter` / `GlassDivider`），**不要在新代码里绕过它们直接画墙面**。
5. `runtime.zip`（`app/src/main/assets/node/`）当前 SHA256 `7C438281B2DDDC502DD13900FEF353FF236435474319008C915448B8C80D70C5`，
   `RUNTIME_VERSION = node26.4.0-dsh0.2.2-rc.5-p3.1`。要改 `host.mjs` 就**重打 zip 并同时升 RUNTIME_VERSION**
   （条目集合 2526 不许变；用 .NET `ZipFile` 或 python，改完记新 SHA256 进证据）。
6. `session.v4` 格式**不许改**；预设/归属等新数据只能放 `files/node/data/`、`plugins.json` 或 prefs。
