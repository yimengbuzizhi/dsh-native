# 10 · 图标方向（仿 RikkaHub 风格）

> 2026-11-06｜用户：「软件的图标，仿照一个 RikkaHub 的风格」→ 选定 **C**。
> 参考：[rikkahub](https://github.com/rikkahub/rikkahub) 的图标（黑底、白色粗形、极简）。

---

## 一、RikkaHub 图标做了什么（拆解）

| 特征 | 做法 | 为什么有效 |
|---|---|---|
| 底 | 近黑圆角方（`#14161A`），带一点光泽 | 在彩色桌面/商店里最跳 |
| 主体 | 一个白色粗形（兔头 + 两只长耳） | 形状一句话说得清 |
| 细节 | 两个黑色竖椭圆眼 | 有"表情"，记得住 |
| 材质 | 白色带轻微渐变/内阴影 | 不扁平，有质感 |
| 文字 | **没有** | 小尺寸下文字必糊 |
| 元素数 | ≤ 4 个 | 48px 也认得出 |

## 二、定稿：C 方案

**黑底 + 白色字母 D + 两根安卓天线 + 品牌蓝窗口。**

- 字母 D：一眼记住产品名（DSH），比鲸鱼更快
- 两根天线：安卓/设备操作的隐喻，和 Rikka 的"耳朵"是同一手法
- 蓝色窗口：唯一强调色，和 App 主色 `#2F6FE0` 一致
- 渐变白：有轻微光泽，不扁平
- 元素少：48px 还能认出 D + 天线

| 文件 | 用途 |
|---|---|
| `icons/20-icon-c-final.svg` | 512 主图（带圆角底，用于商店/关于页） |
| `icons/20-adaptive-foreground.svg` | 自适应前景（66dp 安全区，透明底） |
| `icons/20-adaptive-background.svg` | 自适应背景（深色渐变） |
| `icons/20-monochrome.svg` | 单色（Android 13 主题图标） |
| `exports/ic_launcher_{512,192,144,96,72,48}.png` | 多尺寸导出 |

其余候选（A 鲸鱼机器人、B 蓝底、D 浅色反相）保留在 `icons/` 里做备选。

## 三、落地参数

| 项 | 值 |
|---|---|
| 主色 | `#2F6FE0`（窗口） |
| 底 | `#14161A` → `#0E1014` 渐变 |
| 白形 | `#FFFFFF` → `#D9E0EB` |
| 圆角 | 118/512（约 23%），系统图标会再裁 |
| 安全区 | 前景缩至 72%（66/108dp） |
| 字号 | 无文字 |

## 五、可自定义（不能忘的那条）

图标本身不跟主题变（系统级），但**应用内**的品牌元素可以：

| 可自定义 | 范围 |
|---|---|
| 主题预设 | 6 套（暖白/深海/晴空/纸墨/高对比/跟随系统） |
| Token 覆盖 | 颜色 / 圆角 / 字体 / 背景图 / logo |
| 旧版 4 层 | 外观 / 布局 / 文案 / 动作（含导入导出，规范不变） |
| 组件密度 | 舒适 / 紧凑（管理类页面用紧凑） |
