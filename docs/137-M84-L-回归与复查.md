## 三、`ui.view` 上游核对：它其实不是 DSH API

对真实 DSH 桌面安装包 `D:\dshdsh\resources\app.asar`（213MB）做字符串扫描：

| 搜索 | 结果 |
|---|---|
| `ui.registerView` | **0 命中** |
| `registerView:`（对象方法定义） | **0 命中** |
| `registerView(` | 只命中 Chrome DevTools 内部的 `registerView(e)`（与插件 API 无关） |
| `sessionProjections.register` | 命中 DSH 真实投影服务（`actionCardProjection` 等），证明扫描方法有效 |

结论：`ctx.ui.registerView` 是我们早期从 `docs/04` 的能力清单里推测出来的**预留项**，不是上游 API。
能力清单里它仍标 `implemented=false`，但描述改成「预留项（真实 DSH 包内不存在）」，
不再写成「本版仍 unsupported」那种像欠了上游债的说法。

**因此：DSH 真实插件 API 里，鲸歌已经没有未实现项**（27 条清单中 26 条 implemented + 1 条非上游预留）。
