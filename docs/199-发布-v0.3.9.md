## 四、终端 Shizuku/Root 通道（新功能）

- `BashTool` 新增可选 `identity=app|shell|root`（默认 `app`，**不改变原有行为**）。
- `core:tools` 的 `ShellHost` 加 `supportsElevatedIdentity()` / `runElevated(ElevatedRequest)`；
  `Skill` 契约保持纯 JVM，Android 端由 `Toolchain` 实现 → `DeviceShell.runElevatedCommand`。
- `DeviceShell` 新增 `runElevatedCommand`：root → Shizuku → App 身份链，一次性执行整条命令，
  流式收 stdout/stderr 尾部（≤300k 字符）、超时杀进程树、支持 `cwd`/`env`/`stdin`；
  shell 身份无法进入 app 私有 workdir 时自动改用 `/data/local/tmp` 并在 `note` 说明；
  身份不可用返回结构化文案（不静默降级）。
- 工具 schema/描述（`PromptPack`）新增 `identity` 属性（enum app/shell/root）与使用说明，随每次请求下发给模型。
- 新增真机自检 `--ez dsh_bash_identity_probe true`（`BashIdentityProbe.kt`，可 `--es ..._out <路径>`），
  有 root 的设备上同一探针会给出真正的 root 结果。

## 五、内置插件技能同步

PR #7 改了插件系统（多文件 `dsh.package.json`、单文件导入、Node 适配）但没更新任何 SKILL.md，
AI 仍按 0.3.5 的旧事实回答。本版同步三个随包技能（`BundledSkillSync` 会在启动时更新设备副本）：

- `dsh-plugin-adapter`：新增「0.1 导入入口」表（单文件 `.js/.yaml/.md/.json` 直装、zip 先选原生/Node、
  同 id 跨侧迁移），修正「无相对 require」「Node 没有界面」等过期结论；
- `dsh-plugin-authoring`：新增「多文件包（dsh.package.json，0.3.9）」整节（示例、bootstrap 语义、清单键、
  各 kind 最小声明、64 个/256KB/500 节点上限、常见校验文案、client 入口安全、重载语义）与
  「文件、模块与编码」表（`ctx.assets`/`ctx.data`、fs 二进制、`node:path`、编码垫片）；zip 上限改为 64MB/32MB/64MB/5000/200×；
- `dsh-node-plugin-authoring`：补宿主环境事实（PATH/CA/NODE_PATH/HOME/TMPDIR）、同一模块路径才继承 config、
  web client 容器、`nodehost_install` 路径限制、reload 重拉 manifest。

真机确认 `files/skills/*/SKILL.md` 的 `.bundled-sha256` 与本版 assets 一致。

  全屏按键转发、退出 `clearFocus`）未在本版修，留待与 UI 体验一起做。
- P3（`Backdrop` 默认关动效、顶栏 padding、插件壳选择不匹配不回退 native 等）需要产品决策，未动。
- 插件 `ctx.shell.exec` 仍是 App 身份（与模型侧 `bash identity` 不是同一通道；技能已如实写明）。
- Node 宿主内置 `@deepseek-ai/dsh` 仍是 0.2.2-rc.5，未升级。
