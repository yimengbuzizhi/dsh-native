# 185 · 液态玻璃视觉层（厚透镜设计稿移植）

> 目标：把 `鲸歌 · 厚透镜液态玻璃` 设计稿的视觉语言整体搬进本项目的 Compose UI，
> **布局与信息架构不变**（以本仓库为准），只换「材质 + 动效 + 光」。
> 本文记录取向、令牌、原语与改造点，供后续页面继续套用。

## 1. 取向：不模糊，只做光学暗示

Compose 没有逐帧 backdrop-filter：真做背景模糊要么每帧重采样、要么开 RenderEffect
（API 31+，列表里必掉帧）。设计稿本身也是用「镜面硬边 + 侧壁 + 发丝线 + 色散」
骗眼睛的，所以这里选择**零模糊**：一块玻璃 = 一次 `drawBehind` 里的 6 层渐变/描边。

| 层 | 画什么 | 令牌 |
| --- | --- | --- |
| 1 雾面 | 垂直渐变（顶亮 → 中淡 → 底更淡） | `glassTop/glassMid/glassBottom` |
| 2 镜面 | 顶部 42% 高的高光带 | `rimTop` |
| 3 色散 | 左右各 1.5dp 的冷暖边 | `dispWarm` / `dispCool` |
| 4 侧壁 | 内缩 2.5dp 的浓边（Pill 档跳过） | `wallSide` |
| 5 发丝 | 0.75dp 内描边 | `hairline` |
| 6 回光 | 底部 18% 的反射 | `rimBottom` |

## 2. 令牌：`theme/Liquid.kt`

- `LiquidTokens`：墙面三段色、三团光斑色、玻璃四段色、边缘/发丝/侧壁、色散冷暖、
  环境阴影、噪点强度、跟手光源色。深/浅各一套（`LightLiquidTokens` / `DarkLiquidTokens`），
  由 `DshTheme` 通过 `LocalLiquidTokens` 下发。
- `LiquidRadius`：10/14/18/22/26/30 + pill，比原来的 8/12/16/20/24 整体更圆一档。
- `opticalOuterRadius(inner, padding)`：光学同心圆角 `R_out = R_in + Padding`。
- `LiquidMotion`：按压 `spring(0.72, 900)`、面板 `spring(0.82, 420)`、入场
  `CubicBezier(0.22,1,0.36,1)/340ms`、错峰 45ms。
- `LiquidLevel`：`Pill / Card / Panel / Hero` —— 决定投影高度档位。

## 3. 原语：`component/Glass.kt`

- `Modifier.liquidGlass(shape, level, tint, tintGradient, elevated)`：玻璃背景本体。
- `Modifier.liquidClickable(...)`：按下 0.976 + 白色涟漪，全站可点元素统一走它。
- `Modifier.liquidEnter(index)`：入场淡入 + 上浮 10dp，`index` 决定错峰。
- `GlassSurface` / `GlassPrimaryButton` / `GlassDivider`：容器、主按钮、发丝分隔线。

## 4. 背景：`component/Backdrop.kt`

`LiquidBackdrop(...)` = 墙面垂直渐变 + 三团缓慢漂移的光斑（21/31/43s 无限过渡）
+ 96×96 噪点平铺（打散 AMOLED 暗部色带）+ 跟手光源（指数逼近，收敛即停）。

**性能要点**：光斑相位以 `State<Float>` 形式传进 `drawBehind`，值只在 **draw 阶段**读取，
于是每帧只「重绘」不「重组」——否则整个页面树会被背景动画拖着每帧重组。

## 5. 接线点

| 位置 | 改法 |
| --- | --- |
| `Color.kt` | `surface/surfaceAlt/line/line2` 半透明化；`background` 保持不透明（浮窗/独立 Activity 兜底） |
| `Theme.kt` | 下发 `LocalLiquidTokens`；补 `LocalDarkTheme` 的 provide；`DshTheme2.liquid` |
| `Components.kt` | `DshCard`/`QuickTile`/`DshChip` → `GlassSurface`；`ListRow` 换 `liquidClickable`（签名不变） |
| `component/Settings.kt` | 设置卡片、输入框、选择行全部换玻璃；输入框用更亮的白色 tint |
| `NativeShellRoot.kt` | 整棵壳套一次 `LiquidBackdrop`；宽屏侧栏换整条竖玻璃 + `GlassDivider` |
| `DshDrawer.kt` | 滑出抽屉 `drawerContainerColor = Transparent` + 自带玻璃；宽屏面板交给外壳 |
| 各页面 | 根 `background(c.background)` → `Color.Transparent`（背景由 backdrop 提供） |
| `ChatComposer.kt` | 输入卡、发送珠、图标钮玻璃化 |
| `ChatScreen.kt` | 顶栏换玻璃横条；用户气泡换品牌色玻璃（助手正文仍直接铺在墙面上） |

## 6. 已知取舍

- 不引入 blur/RenderEffect：低端机列表滑动的帧率优先。
- 页面底色透明化依赖「壳里一定有 `LiquidBackdrop`」；`SafeModeScreen` 与
  Surface/WebView 壳仍是自己的不透明底（它们不在这条背景链上）。
- 半透明 `surface` 让弹窗/底部卡片透出背景；深色主题下 70% 不透明度仍可读。
