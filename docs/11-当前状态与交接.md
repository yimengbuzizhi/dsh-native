## 八、坑（已经踩过的）

1. Gradle 官方源 ~50KB/s → 换腾讯镜像 `mirrors.cloud.tencent.com/gradle/`
2. 截图用 Chrome headless：`--headless=new --screenshot=... --window-size=W,H`；透明底要 `--default-background-color=00000000`
3. 不要用 PowerShell 正则批量改中文 SVG（会写坏/加 BOM）；改文件用 Python + UTF-8 无 BOM
4. 方案里 20196 B 的旧 payload 树是干扰项，别拿它当基线
