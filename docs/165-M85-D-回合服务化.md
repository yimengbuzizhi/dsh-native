# 165 · M85-D：回合服务化（agent/v1 + builtin.agent.dsh + JS echo agent）

> 「一个可停用/可同 id 覆盖的插件角色」。真机：OPPO A55 5G（PEMM00 / 720×1600 / Android 13）。
> 本批未发布（0.3.2 / versionCode 5）。

## 1. 结论

1. **默认回合 = 内置插件 `builtin.agent.dsh`**：现有 `TurnEngine` 原样跑（请求/工具/压缩/审批/
   goal/子代理全保留），只是登记成 agent/v1 插件；关掉它 = 聊天页「回合安全模式」提示，不崩溃，
   可一键恢复。
2. **回合可换**：第三方 JS 插件用 `ctx.agent.register({id,label,run})` 声明；选中后每条消息由它跑，
   返回 `{stopReason,text}` 由宿主按正常会话事件落库。演示 echo 插件输入什么就回什么。
3. **同 id 覆盖 + 回退**：第三方声明 `agent id = builtin.agent.dsh` 即可接管默认回合；插件停用后
   自动回内置 `TurnEngine`（覆盖后回退原实现，不是安全模式）；`native` 永远指向内置实现。
4. 切换入口两条：插件页「回合插件」分组点选；调试通道 `--es dsh_agent <id|native>`，
   清单/解析 dump：`--es dsh_agent_list <绝对路径>`。
5. **M84-B 142/142 PASS**（M85-D 最终 APK，`docs/m84b-check-m85d.json`，time 08:17:18）。

## 2. 实现

### 2.1 `agent/v1` 契约（新模块 `:core:agent-api`，纯 Kotlin）

`AgentContract.kt`：契约名 `agent/v1`、内置 id `builtin.agent.dsh`、`AgentCandidate`（agentId /
pluginId / builtin / enabled / permitted）、`ResolvedAgent`、`AgentResolution`，以及**选择规则**
`AgentRouting.resolve`（可在 JVM 单测里锁死）：

| `dsh_agent` / pref | 解析 |
|---|---|
| 空 / `builtin.agent.dsh` | 默认角色：启用 + `agent` 授权的**同 id 第三方优先**，否则内置 native |
| `native` | 强制内置 native（不给同 id 接管）；内置被停用 = 安全提示 |
| `插件id` | 该插件声明的第一个回合 |
| `插件id#回合id` / `回合id` | 精确选择 |
| 选不中 | `Unavailable(reason)`：未安装 / 已停用 / 缺 `agent` 授权（**不偷偷回退**） |
| 选中同 id 覆盖，插件停用 | 回退内置 native（「覆盖后回退原实现」） |

单测 `AgentRoutingTest` **11/11**（默认/同 id/停用/缺授权/native 强制/回退/pref 规范化）。

### 2.2 插件角色（`:core:plugins`）

- JS API：`ctx.agent.register({ id, label, run })`；定义留在常驻 runtime，元数据进 `__dsh.agents`；
- 常驻 dispatch：`agent.run({ id, turn:{turnId,sessionId,input,state} }, ctx)` →
  `{ok, stopReason, text}`；`run` 允许 async，异常/超时归一成 `{ok:false,error}`；
- ctx 原语（v1 已开放）：`ctx.notify` / `ctx.status` / `ctx.abort` / `ctx.tools.names()`；
  `ctx.tools.invoke` / `ctx.llm.stream` / `ctx.storage.append` **明确返回 `UNSUPPORTED`**
  （M85-E 接存储/模型后再开放，不静默成功）；
- 权限：新 `agent`（导入即允许，但必须被用户/调试通道**选中**才生效；停用/撤销立刻失效）；
- 记录/持久化：`PluginAgent(id,label)` 进 `plugins.json`（与 shells/projections 同一条读写路径）；
- 常驻运行时：声明了 agent 的启用插件会起 runtime（`sync` 条件加 `record.agents`），
  dump 里 `resident[].agents[]`；插件停用 → runtime 关闭、`ctx` 调用一律 PERMISSION_DENIED/没有运行时。

### 2.3 内置回合插件 `builtin.agent.dsh`

- `BuiltinPlugins` 新增 `kind = Agent` 的目录项（默认开，`builtin_plugins_disabled` 持久化）；
- 宿主 `AppViewModel` 在**每次发消息前**重新解析 `dsh_agent`：
  - 内置实现 → `live.engine.startTurn(...)`（现有行为，一字未改）；
  - 第三方实现 → `runPluginAgentTurn(...)`：宿主落 `request/header? → turn/start → step/start →
    user/message → assistant/message → step/end → turn/end`（与内置引擎同会话格式），
    然后 dispatch `agent.run`；结果正文写回消息与会话文件；
  - 没有可用回合 → `state.attachError` + 聊天页「回合安全模式」横幅，发送被拦下（不崩溃）；
  - 第三方回合在 v1 只支持纯文本轮：图片/附件/后台通知轮会明确提示切回内置引擎。
- 一键恢复：`restoreBuiltinAgent()` 重新打开 `builtin.agent.dsh` 并写 `dsh_agent=native`。

### 2.4 UI / 调试通道

- 插件页「回合插件（N）」分组：内置 dsH 引擎 + 所有 `ctx.agent.register` 的候选，
  显示「使用中 / 选择 / 不可用（原因）」，点行切换；
- 聊天页：第三方回合时顶部一条「回合插件：…（提供者）」；无可用回合时红色「回合安全模式」+
  「恢复内置回合」按钮；
- `--es dsh_agent <插件id[#回合id]|native|builtin.agent.dsh>`：冷启写 pref，热启直接切；
- `--es dsh_agent_list <路径>`：pref / active / safety / candidates / 常驻登记的回合落盘。

## 6. 没做 / 限制（不许当成已完成）

1. **JS 回合只有纯文本**：附件/图片/后台通知轮没有拆进 `agent/v1`，会提示切回内置引擎；
   也没有逐 token 流式（返回值一次性写回）。
2. **ctx 原语只开放 notify/status/abort/tools.names**；`tools.invoke` / `llm.stream` /
   `storage.append` 明确返回 `UNSUPPORTED`，留给 M85-E（存储/模型契约化）。
3. **停止语义**：JS dispatch 是阻塞调用，用户点停止会置 `ctx.abort()` 位并取消宿主协程，
   1.5s 兜底会清 UI；插件若无视 abort 一直跑，最多等 120s 超时。未做「强制杀 JS」。
4. **同 id 覆盖只验证 agent 角色**；native 壳/agent 仍不做 DEX 动态加载（`docs/144` §10 非目标）。
5. `builtin.agent.dsh` 是 native 实现，行为与 M84 一致；**没有**重写 TurnEngine，也没有删任何既有逻辑。
6. M85-E（storage/prompt/model）与 M85-F（WebView 壳/浮动窗 Surface/capability/v1/三终点/发版准备）未开始。
