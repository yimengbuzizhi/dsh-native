## 怎么改

- SVG 是纯文本，直接改坐标/颜色即可；用浏览器打开就能看。
- 重新出 PNG：`make-overview.py` 负责拼总览图；单页渲染命令：
  ```
  chrome --headless=new --screenshot=out.png --window-size=390,844 screens/01-chat.svg
  ```
